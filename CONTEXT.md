# CertMuse Content

This context defines the shared language for managing question content through authoring and review.

## Language

**Draft question**:
A question that can be edited and submitted for review.
_Avoid_: Offline question, approved question

**Pending-review question**:
A question awaiting an explicit review decision and unavailable for editing.
_Avoid_: Submitted question, reviewing question

**Rejected question**:
A question returned by review with a mandatory reason and awaiting correction.
_Avoid_: Failed question, draft question

**Published question**:
A question available for use after review approval.
_Avoid_: Approved question, online question

**Take offline**:
The action that returns a published question to draft; it is not a persistent question status.
_Avoid_: Offline status
