- 后端：JaCoCo 仅统计 `backend/ruoyi-modules/ruoyi-certmuse` 已编译的生产类；RuoYi 原生 Maven 模块不在覆盖率分母。没有将已实施的首次诊断、学习目标或 onboarding 排除。
- 管理端：只统计 `src/api/certmuse`、`src/views/certmuse`、`src/components/certmuse`，及实际被应用导入的 `auth-routing.ts`、`import-progress-events.ts`。排除测试、声明、Mock、未接入的重复 `real.ts` 文件和明确仅显示“待接入”占位页（如 `EmptyBusinessPage`、考试安排、洞察、学习规则及五个详情/编辑占位路由）。

这些排除项均在 `web/admin/vitest.config.ts` 与 `web/student/vitest.config.ts` 中显式列出，未在本次收尾时扩大。
