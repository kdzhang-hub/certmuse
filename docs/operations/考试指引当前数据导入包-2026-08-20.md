# 考试指引当前数据导入包

导出日期：2026-08-20（Asia/Shanghai）

可执行数据文件：[`tools/ops/import-exam-guidance-current-2026.sql`](../../tools/ops/import-exam-guidance-current-2026.sql)。它是从当前本地 `certmuse` PostgreSQL 实例导出的可重复执行数据包，供同事在新本地库或服务器库同步当前考试指引基础数据。

## 使用范围

导入前目标库必须已经执行至 `20260820` 的 CertMuse 数据库迁移，并且已经有“系统架构设计师”及以下三个科目：`COMPREHENSIVE`、`CASE_ANALYSIS`、`ESSAY`。

该文件只会写入或更新以下内容：

1. 两个草稿考期；
2. `2026-H1` 的一条系统架构设计师安排及三个科目场次；
3. 34 个考区的长期入口、实施机构、联系电话与排序。

它不会发布考期，也不会创建任何报名信息。遇到同编码的已发布或 legacy 考期时会终止，避免覆盖线上已发布事实。

本地或服务器上可使用：

```powershell
psql "$env:CERTMUSE_DB_URL" -v ON_ERROR_STOP=1 -f tools/ops/import-exam-guidance-current-2026.sql
```

若没有 `CERTMUSE_DB_URL`，由部署人员使用其已配置的 PostgreSQL 连接串替换。不要把数据库密码写入脚本或提交到仓库。

## 导入后核对

```sql
SELECT period_code, status, official_source_url, source_published_at::date
FROM cm_exam_period
WHERE period_code IN ('2026-H1', '2026-H2')
ORDER BY period_code;

SELECT period.period_code, count(schedule.id) AS schedules, count(session.id) AS sessions
FROM cm_exam_period period
LEFT JOIN cm_exam_schedule schedule ON schedule.exam_period_id = period.id
LEFT JOIN cm_exam_schedule_session session ON session.exam_schedule_id = schedule.id
WHERE period.period_code IN ('2026-H1', '2026-H2')
GROUP BY period.period_code
ORDER BY period.period_code;

SELECT count(*) AS regions FROM cm_exam_region WHERE status = 'enabled';
```

预期结果：`2026-H1` 为 1 条安排、3 条场次；`2026-H2` 为 0 条安排、0 条场次；启用考区为 34 个。
