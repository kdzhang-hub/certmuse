# 学习画像总分后端接口契约 V1

```yaml
contract_id: learner-profile-overall-score-v1
contract_version: 1.0
module: learning-profile
route: /api/learning/profile/overall-score
scope: learner-current-goal-overall-score-read
status: implementation_ready
updated_at: 2026-08-17
```

## 1. 目标与边界

本接口只为学生端“学习画像”页面顶部提供当前学习目标资格的总体评分。知识点的重要度、掌握程度、题量和练习入口继续复用既有 `GET /api/assessment/knowledge-practices/setup`。

总体评分直接读取当前目标 `cm_overall_profile.overall_ability`。本接口不重新计算画像、不补默认分、不触发任务、不写入学习事实，也不返回科目、知识点、准备度、通过概率、证据或公式。

## 2. 请求与权限

```http
GET /api/learning/profile/overall-score
```

- 无请求体、无必需查询参数、不要求 `X-Request-Id`；未知查询参数和请求头不得影响查询范围。
- 调用者必须已登录，并同时具有 `certmuse:student` 与 `certmuse:profile:overall-score:query` 权限。
- `userId` 只能从登录上下文取得；当前 `goalId`、`certificationId` 和 `syllabusVersionId` 由服务端根据该用户查询，客户端不得传递或影响这些值。
- 当前目标为 `active` 或 `paused` 时可读取；不存在可查看目标时返回 409。
- 响应必须携带 `Cache-Control: no-store`。

新细粒度权限默认授予所有有效 `student` 角色，只用于接口治理，不作为会员、套餐、灰度或画像计算开关。

## 3. 成功响应

真实 HTTP Status 必须等于 `R.code`。`overallScore` 为 JSON number 或 `null`，数据库类型为 `numeric(12,8)`，最多保留 8 位小数；前端仅在展示时四舍五入到一位小数。时间为 ISO-8601 带时区时间。

```ts
interface OverallScoreVo {
  certificationName: string;
  overallScore: number | null;
  calculatedTime: string | null;
}
```

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "certificationName": "系统架构设计师",
    "overallScore": 72.4375,
    "calculatedTime": "2026-08-17T10:20:00+08:00"
  }
}
```

尚未形成有效总体画像时返回：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "certificationName": "系统架构设计师",
    "overallScore": null,
    "calculatedTime": null
  }
}
```

### 3.1 返回规则

1. 服务端读取登录用户唯一 `active` 或 `paused` 目标的资格名称。
2. 使用 `user_id + goal_id` 左连接读取 `cm_overall_profile`。
3. 记录不存在、`overall_ability IS NULL` 或 `calculated_time IS NULL` 时，成功返回两个 `null`，不得返回默认值、历史目标分数或单场诊断分。
4. 有效记录的分数必须位于 0 至 100，服务端使用 `BigDecimal` 原样投影；时间使用 `OffsetDateTime`。
5. 接口只读取已持久化投影，不刷新证据、新鲜度或计算时间。

## 4. 失败响应

业务失败使用稳定的 `data.errorCode`；401 和 403 沿用认证授权兼容格式，`data` 不作承诺。

| HTTP / `R.code` | `errorCode` | 条件 | `retryable` |
| --- | --- | --- | ---: |
| 401 / 403 | 不承诺 | 未登录或缺少任一必需权限 | 不承诺 |
| 409 | `LEARNING_GOAL_NOT_ACTIVE` | 当前用户没有 `active` 或 `paused` 目标 | false |
| 500 | `INTERNAL_SERVER_ERROR` | 未预期查询、映射或序列化失败 | true |

409 响应：

```json
{
  "code": 409,
  "msg": "当前没有可查看的学习目标",
  "data": {
    "errorCode": "LEARNING_GOAL_NOT_ACTIVE",
    "retryable": false,
    "traceId": null,
    "fieldErrors": [],
    "details": null
  }
}
```

未知 500 由 CertMuse 模块全局异常处理器生成安全文案和非空 `traceId`，不得泄露 SQL、表名、堆栈或内部数据。

## 5. 行为、安全与可观测性

- GET 只读，不使用幂等记录，不产生画像变化、报告、任务、缓存写入或异步任务。
- 暂停目标只读返回已持久化总分，不恢复目标或允许新的正式作答。
- 响应不得包含用户 ID、目标 ID、知识点、证据、答案、规则版本、SQL、表名或堆栈。
- 普通成功查询不打印业务明细日志；未知异常由模块边界关联 `traceId` 记录一次完整 cause，业务代码不得重复记录或主动输出敏感内容。

## 6. 验收用例

1. 有当前目标且分数为 `72.4375`：返回 200、资格名称、精确分数和真实计算时间。
2. 当前目标没有画像记录：返回 200，分数和时间均为 `null`。
3. 当前画像分数或计算时间任一为空：返回 200，两个字段均为 `null`。
4. 暂停目标存在画像：返回 200，不改变目标状态。
5. 没有当前目标：返回真实 HTTP 409 和 `LEARNING_GOAL_NOT_ACTIVE`。
6. 携带伪造范围参数：不得影响登录用户范围；没有当前目标时仍返回 409。
7. 缺少 `certmuse:student` 或 `certmuse:profile:overall-score:query`：返回 401/403，不返回总分。
8. 未预期异常：返回真实 HTTP 500、`INTERNAL_SERVER_ERROR` 和非空 `traceId`。
9. 响应包含 `Cache-Control: no-store`，且不存在科目、知识点、准备度、通过概率、证据或公式字段。

## 7. 发布要求

先执行权限迁移并默认授权有效学生角色，再强制现有学生会话重新登录以刷新会话权限，最后部署接口并使用新会话完成 200、409 和 403 冒烟验证。
