# U13 模拟试卷展示、题干预览与开考后端接口契约 V1.2

> 契约版本：V1.2
> 状态：展示接口已实现；开考门禁关闭，必须与答题、保存、主动交卷、超时自动交卷和结果接口同期启用
> 消费端：学生端「题库 → 模拟试卷」页
> 当前生产范围：平台发布的固定模拟卷展示和已发布题干预览；不包含动态组卷、主观题评分和正式考试答题闭环。

## 1. 目标与边界

本契约为登录用户提供模拟卷筛选初始化、已发布模拟卷列表、试卷说明和正式开考或续考入口。模拟卷来源固定为：

`cm_collection_current → cm_collection_revision(status='published', collection_type='SIMULATION') → cm_collection_item → cm_question_revision`

学生端只读取 `cm_collection_current` 当前指向的发布修订，不展示草稿、审核中、驳回、历史或已下架修订，不调用管理端题集接口。

游客只能看到前端静态的模拟考试功能说明，不得调用本契约接口查看模拟卷列表或开始模拟考试。登录但没有当前目标的用户可以查看列表和说明；只有当前有效目标资格与模拟卷资格一致时才可能开考。

页面筛选只使用现有模型可靠提供的资格、考纲版本和题集名称。当前数据库没有模拟卷年份、批次和卷型字段，本契约不提供这些筛选。

页面操作固定为：

- `查看试卷`：查看科目、题型、题量、总分、时长、考试规则及按题序排列的已发布题干；不返回选项、答案、解析或评分数据。
- `开始练习/继续练习`：进入正式计时考试。开始后才由后续答题契约返回冻结题面。

模拟卷只提供正式考试模式；查看试卷是独立的只读题干预览，不能创建、恢复或影响正式考试会话。当前业务已取消主观题 AI 评分生产能力，因此 V1.2 只允许单科且所有题目均为可同步判分 `CHOICE` 的模拟卷开考；其他已发布模拟卷可以展示和预览题干，但必须明确标记暂不可开考。

## 2. 数据设计与迁移前提

### 2.1 已有数据能力

| 用途 | 表或字段 | 当前结论 |
|---|---|---|
| 当前发布模拟卷 | `cm_collection_current`、`cm_collection_revision` | 可直接使用 |
| 题序、固定题目版本和分值 | `cm_collection_item` | 可直接使用 |
| 科目和题型 | `cm_collection_item → cm_question_revision → cm_question` | 查询时聚合；V1.1 必须恰好一个科目 |
| 会话来源修订 | `cm_learning_session.collection_revision_id` | 字段已经由首次诊断迁移创建，禁止重复新增 |
| 目标并发版本 | `cm_user_goal.row_version` | 开考请求必须传 `expectedGoalVersion` |
| 答题和报告 | `cm_session_question`、`cm_question_attempt`、`cm_attempt_answer`、`cm_assessment_report` | 后续答题链路复用 |

### 2.2 开考所需迁移

正式迁移文件必须新增在 `backend/script/sql/postgres/certmuse/`，不得修改既有迁移。以下 SQL 表达冻结的数据要求，不作为直接执行脚本；实施时需采用项目既有迁移风格、幂等检查和验证语句。

```sql
-- collection_revision_id 已存在，只补外键；约束名存在时应由迁移预检阻止重复部署。
ALTER TABLE cm_learning_session
    ADD COLUMN IF NOT EXISTS timing_mode varchar(20),
    ADD COLUMN IF NOT EXISTS duration_seconds_snapshot integer,
    ADD COLUMN IF NOT EXISTS deadline_time timestamptz,
    ADD COLUMN IF NOT EXISTS formal_attempt_no integer;

ALTER TABLE cm_learning_session
    ADD CONSTRAINT fk_cm_learning_session_collection_revision
    FOREIGN KEY (collection_revision_id)
    REFERENCES cm_collection_revision(id) ON DELETE RESTRICT;

ALTER TABLE cm_learning_session
    ADD CONSTRAINT ck_cm_learning_session_simulation_fields CHECK (
      session_type <> 'simulation' OR (
        collection_revision_id IS NOT NULL
        AND timing_mode = 'standard'
        AND duration_seconds_snapshot > 0
        AND formal_attempt_no >= 1
        AND started_time IS NOT NULL
        AND deadline_time > started_time
      )
    ) NOT VALID;

CREATE UNIQUE INDEX uk_cm_learning_session_active_simulation_goal
    ON cm_learning_session(user_id, goal_id)
    WHERE session_type='simulation'
      AND status IN ('created', 'in_progress', 'submitted', 'settling');

CREATE UNIQUE INDEX uk_cm_learning_session_simulation_attempt
    ON cm_learning_session(user_id, goal_id, collection_revision_id, formal_attempt_no)
    WHERE session_type='simulation';
```

迁移执行前必须审计既有 `session_type='simulation'` 数据。当前功能尚未上线时预期为零；如果存在旧数据，必须先确定其来源修订和处理方式，不得以虚构修订或默认时间回填。处理完成后再 `VALIDATE CONSTRAINT ck_cm_learning_session_simulation_fields`。

现有会话类型约束已经包含 `simulation`，不得重复创建或删除该枚举值。正式迁移还必须通过 `verify_local.sql` 验证外键、检查约束和两个唯一索引。

## 3. 通用接口约定

- 本契约所有接口均要求登录。身份只从服务端登录态取得，客户端不得传 `userId` 或 `goalId`。
- 业务接口要求学生身份与 `certmuse:student` 权限；401/403 沿用认证组件兼容格式，`data=null`。
- 当前目标指当前用户唯一 `cm_user_goal.status='active'` 目标。没有当前目标不阻止查看列表和说明，只阻止开考。
- ID 使用十进制正整数字符串。时间为 ISO-8601 含偏移量字符串，业务时区固定 `Asia/Shanghai`。
- 成功响应使用 `R<T>`，真实 HTTP Status 与 `R.code` 都为 200。
- 4xx 默认 `traceId=null`；500 必须返回安全文案和非空 `traceId`。失败结构见第 7 节。
- 服务端不接受客户端指定排序。所有响应数组按本文定义稳定排序。

## 4. 接口定义

### 4.1 查询页面初始化数据

`GET /api/assessment/simulations/setup`

认证：必须登录。
权限：`certmuse:student`。
请求参数：无。

资格和考纲选项只包含至少存在一份“当前发布模拟卷”的组合，不能从分页列表当前页推导。资格按 `sort_order ASC, id ASC`；考纲版本按 `published_date DESC NULLS LAST, id DESC`。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "serverTime": "2026-08-18T10:00:00+08:00",
    "timezone": "Asia/Shanghai",
    "currentGoal": {
      "id": "1950000000000000001",
      "certificationId": "900000000000000001",
      "certificationName": "系统架构设计师",
      "syllabusVersionId": "900000000000000021",
      "syllabusVersionName": "第二版",
      "version": 3
    },
    "certifications": [{
      "id": "900000000000000001",
      "name": "系统架构设计师",
      "syllabusVersions": [{
        "id": "900000000000000021",
        "name": "第二版"
      }]
    }]
  }

```

无当前目标时 `currentGoal=null`，仍返回可浏览的资格和考纲选项。

### 4.2 查询已发布模拟试卷

`GET /api/assessment/simulations`

认证：必须登录。
权限：`certmuse:student`。

| 参数 | 必填 | 规则 | 空值语义 |
|---|---:|---|---|
| `certificationId` | 否 | 十进制正整数 | 不限资格 |
| `syllabusVersionId` | 否 | 十进制正整数 | 不限考纲版本；与资格不匹配时返回空分页 |
| `keyword` | 否 | 去首尾空白；空字符串按未传处理；非空最长 100 字符 | 不限名称 |
| `pageNum` | 否 | 整数，默认 1，范围 1–10000 | 默认 1 |
| `pageSize` | 否 | 整数，默认 10，范围 1–50 | 默认 10 |

查询必须同时满足：

- `cm_collection_current.collection_revision_id = cm_collection_revision.id`；
- 修订 `status='published'` 且 `collection_type='SIMULATION'`；
- 资格及考纲本身可见；
- 题集父记录未逻辑停用。

固定排序：`published_time DESC, collection_id DESC`。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "rows": [{
      "collectionId": "1950000000000001001",
      "revisionId": "1950000000000001101",
      "collectionCode": "SIM-SA-COM-001",
      "collectionName": "系统架构设计师综合知识模拟卷（一）",
      "certificationId": "900000000000000001",
      "certificationName": "系统架构设计师",
      "syllabusVersionId": "900000000000000021",
      "syllabusVersionName": "第二版",
      "subject": {
        "id": "900000000000000011",
        "name": "综合知识"
      },
      "questionTypes": ["CHOICE"],
      "questionCount": 75,
      "totalReportScore": 75.00,
      "durationMinutes": 150,
      "publishedTime": "2026-08-18T10:00:00+08:00",
      "access": {
        "action": "START",
        "canStart": true,
        "blockCode": null,
        "activeSessionId": null,
        "activeAnswerPath": null
      }
    }],
    "total": 1
  }
}
```

`questionTypes` 按 `CHOICE, CASE, ESSAY` 固定顺序去重。科目聚合结果不是恰好一个时，`subject=null` 且禁止开考。

`access` 规则：

| 条件 | action | canStart | blockCode |
|---|---|---:|---|
| 无当前目标 | `BLOCKED` | false | `LEARNING_GOAL_NOT_ACTIVE` |
| 当前目标资格不一致 | `BLOCKED` | false | `GOAL_CERTIFICATION_MISMATCH` |
| 当前卷多科或无科目 | `BLOCKED` | false | `SIMULATION_SUBJECT_SCOPE_INVALID` |
| 含 `CASE/ESSAY` 或不可同步判分题 | `BLOCKED` | false | `SIMULATION_SUBJECTIVE_NOT_SUPPORTED` |
| 当前目标存在另一份活动模拟考试 | `BLOCKED` | false | `SIMULATION_SESSION_IN_PROGRESS` |
| 当前卷存在本人活动会话 | `RESUME` | true | null |
| 其余满足开考条件 | `START` | true | null |

当 `action='RESUME'` 时必须返回当前卷的 `activeSessionId/activeAnswerPath`。当另一份模拟卷占用当前目标时，列表不得向所有行泄露该卷题目，只允许返回其本人会话 ID 和恢复路径。

### 4.4 查看已发布试卷题干

`GET /api/assessment/simulations/{collectionId}/preview`

认证：必须登录。
权限：`certmuse:student`。
路径参数：`collectionId`，十进制正整数。

只查询该题集当前发布的 `SIMULATION` 修订，按 `cm_collection_item.item_order ASC` 返回全部固定题目。该接口是明确启用的预览边界，只返回题号、题型和题干；严禁返回选项、正确答案、解析、知识点、图片地址、评分、审核或管理员字段。草稿、历史、下架或题集逻辑停用时返回 `404 SIMULATION_NOT_FOUND`。

```json
{
  "code": 200,

  "data": {

    "revisionId": "1950000000000001101",
    "collectionName": "系统架构设计师综合知识模拟卷（一）",
```

### 4.5 开始或恢复模拟考试

`POST /api/assessment/simulations/{collectionId}/sessions`

认证：必须登录。
权限：`certmuse:student`。
请求头：`X-Request-Id` 必填，RFC 4122 UUID；重复提交拦截关闭，由业务幂等处理。
路径参数：`collectionId`，十进制正整数。

请求体：

```json
{
  "expectedRevisionId": "1950000000000001101",
  "expectedGoalVersion": 3
}
```

| 字段 | 必填 | 规则 |
|---|---:|---|
| `expectedRevisionId` | 是 | 列表或说明返回的十进制正整数修订 ID |
| `expectedGoalVersion` | 是 | 整数，范围 0–9223372036854775807 |

服务端在同一事务内：

1. 按当前用户锁定唯一活动目标，校验 `row_version=expectedGoalVersion`；
2. 锁定 `cm_collection_current`、父题集和当前发布修订，校验 `current revision=expectedRevisionId`、类型为 `SIMULATION`、状态为 `published`；
3. 校验目标资格与试卷资格一致、题序连续、题数与总分一致、时长有效、恰好一个科目，并确认全部题均为已发布且可同步判分的 `CHOICE`；
4. 查询当前用户和目标的 `created/in_progress/submitted/settling` 模拟会话：同一修订的 `created/in_progress` 会话直接恢复；不同修订或不可恢复状态返回活动会话冲突；
5. 锁定该用户、目标和修订的历史会话，计算 `formalAttemptNo=max+1`；首次为 1，之后均为重考；
6. 创建会话并在同一事务内推进到 `in_progress`，固定 `collection_revision_id`、资格、考纲、科目、规则版本、`timing_mode='standard'`、`duration_seconds_snapshot`；
7. 以服务端同一个 `startedTime` 计算 `deadlineTime=startedTime+durationSeconds`，按题集题序写入全部 `cm_session_question` 的题面、判分和知识点快照；
8. 不为未答题预创建 `cm_question_attempt` 或 `cm_attempt_answer`。

成功示例：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "serverTime": "2026-08-18T10:00:00+08:00",
    "sessionId": "1950000000000002001",
    "collectionId": "1950000000000001001",
    "revisionId": "1950000000000001101",
    "resumed": false,
    "formalAttemptNo": 1,
    "isRetest": false,
    "startedTime": "2026-08-18T10:00:00+08:00",
    "durationSeconds": 9000,
    "deadlineTime": "2026-08-18T12:30:00+08:00",
    "answerPath": "/learning/mock-exams/session?sessionId=1950000000000002001"
  }
}
```

恢复时保留原 `startedTime`、`deadlineTime`、修订、题目快照和作答事实，返回 `resumed=true`。已到截止时间的会话不得以本接口临时取消或直接新建重考，必须先由冻结的超时自动交卷流程完成结算。

## 5. 开考幂等与并发

- 幂等动作码固定为 `SIMULATION_START`。规范化载荷至少包含 `userId`、`collectionId`、`expectedRevisionId`、`expectedGoalVersion`。
- 同一 `X-Request-Id` 与相同规范化载荷成功重试时，精确回放首次成功响应；载荷不同返回 409 `SIMULATION_IDEMPOTENCY_CONFLICT`。
- 不同请求号并发开考时，数据库 `uk_cm_learning_session_active_simulation_goal` 保证一个目标最多一场活动模拟考试。唯一冲突后重新读取：同卷可恢复则返回同一会话，不同卷返回 `SIMULATION_SESSION_IN_PROGRESS`。
- `formalAttemptNo` 必须在锁定目标及相关历史会话后计算，并由唯一索引兜底，不得使用未加锁的 `count(*)+1`。
- 管理员在列表加载后切换当前发布修订时，旧 `expectedRevisionId` 开考必须返回版本变化，不得静默进入新修订。
- 用户在列表加载后切换、暂停或更新当前目标时，旧 `expectedGoalVersion` 开考必须返回目标版本变化。

## 6. 发布、下架和上线规则

1. 新开考只使用调用时 `cm_collection_current` 指向的发布修订；既有会话只使用其冻结修订和快照。
2. 试卷下架或发布新修订不得改变既有会话的题目、时长和报告归属。
3. 模拟卷题序和每题分值严格来自 `cm_collection_item`，开考时不得随机组题。
4. 标准计时不允许暂停。客户端倒计时只用于展示，超时以服务端 `deadlineTime` 为准。
5. V1.1 后端开考能力只能在答题卡读取、单题答案保存、主动交卷、超时自动交卷、同步判分、报告和画像结算契约及实现全部可用后启用。
6. 上述完整链路未启用前，列表可以上线，但所有行必须返回 `canStart=false, blockCode='SIMULATION_NOT_OPEN'`；不得创建正式会话。

## 7. 失败响应

除 401/403 外，统一结构：

```json
{
  "code": 409,
  "msg": "试卷版本已经更新",
  "data": {
    "errorCode": "SIMULATION_REVISION_CHANGED",
    "retryable": false,
    "traceId": null,
    "fieldErrors": [],
    "details": {
      "currentRevisionId": "1950000000000001102"
    }
  }
}
```

| HTTP | errorCode | 触发条件 | retryable | 前端行为 |
|---:|---|---|---:|---|
| 400 | `SIMULATION_REQUEST_INVALID` | 查询、路径、请求头或请求体格式错误 | false | 显示字段错误 |
| 404 | `SIMULATION_NOT_FOUND` | 不存在、非模拟题集或没有当前发布修订 | false | 返回列表并刷新 |
| 409 | `SIMULATION_REVISION_CHANGED` | 当前发布修订与 `expectedRevisionId` 不同 | false | 刷新列表和说明，不自动开考 |
| 409 | `SIMULATION_GOAL_VERSION_CONFLICT` | 当前目标版本与预期不一致 | false | 刷新初始化数据 |
| 409 | `SIMULATION_SESSION_IN_PROGRESS` | 当前目标存在另一场或不可恢复的活动模拟考试 | false | 使用 `details.answerPath` 引导处理原考试 |
| 409 | `SIMULATION_IDEMPOTENCY_CONFLICT` | 请求号载荷冲突或不能回放 | false | 新请求号只能用于用户重新发起的操作 |
| 422 | `LEARNING_GOAL_NOT_ACTIVE` | 登录用户没有活动目标 | false | 引导建立或恢复目标 |
| 422 | `GOAL_CERTIFICATION_MISMATCH` | 目标资格与试卷资格不同 | false | 引导切换目标 |
| 422 | `SIMULATION_SUBJECT_SCOPE_INVALID` | 模拟卷没有科目或包含多个科目 | false | 提示试卷维护中 |
| 422 | `SIMULATION_SUBJECTIVE_NOT_SUPPORTED` | 含主观题或其他不可同步判分题 | false | 提示该卷暂未开放 |
| 422 | `SIMULATION_PAPER_UNAVAILABLE` | 空卷、时长、题序、总分或题目状态不合法 | false | 提示试卷维护中并刷新 |
| 503 | `SIMULATION_NOT_OPEN` | 完整考试链路尚未启用 | true | 保留列表，禁止开考 |
| 503 | `SIMULATION_RULE_VERSION_UNAVAILABLE` | 无可用规则版本 | true | 稍后重试 |
| 500 | `SIMULATION_SYSTEM_FAILURE` | 未预期故障 | true | 显示安全提示和 `traceId` |

400 字段错误码只使用 `REQUIRED`、`INVALID_FORMAT`、`OUT_OF_RANGE`，字段路径使用 `expectedRevisionId`、`expectedGoalVersion`、查询参数名或 `X-Request-Id`。

`SIMULATION_SESSION_IN_PROGRESS.details`：

```json
{
  "sessionId": "1950000000000002001",
  "collectionId": "1950000000000001000",
  "answerPath": "/learning/mock-exams/session?sessionId=1950000000000002001"
}
```

## 8. 安全与可观测性

- 列表和说明接口不得返回题干、选项、正确答案、解析、判分快照、知识点快照、内部审核信息或管理员 ID；题干仅能由 4.4 预览接口返回。
- 4.4 预览接口只能返回当前发布题集固定修订的 `questionOrder`、`questionType` 和 `stem`，不得因展示便利扩展为选项、答案、解析、图片或评分预览。
- 用户只能读取、恢复和提交本人会话；所有会话查询必须同时按 `sessionId + userId` 限定。
- 开考与后续考试日志只记录 `userId`、`goalId`、`collectionId`、`revisionId`、`sessionId`、`requestId`、结果码和 `traceId`，禁止记录题目和答案内容。
- `X-Request-Id` 写入幂等记录与业务审计。500 完整异常只在边界记录一次，响应使用相同非空 `traceId`。

## 9. 验收用例

| 用例 | 输入或前置状态 | 可断言结果 |
|---|---|---|
| 游客访问接口 | 未登录调用任一接口 | 401，`data=null` |
| 初始化选项 | 存在已发布和草稿模拟卷 | 只返回具有当前发布模拟卷的资格/考纲组合 |
| 无目标初始化 | 已登录、无 active goal | 200，`currentGoal=null` |
| 已发布列表 | 无筛选 | 仅当前 `published + SIMULATION` 修订，排序稳定 |
| 不匹配筛选 | 资格与考纲不属于同一组合 | 200，空分页 |
| 非法分页 | `pageSize=51` | 400，`pageSize/OUT_OF_RANGE` |
| 查看说明 | 当前发布模拟卷 | 200，无题目、答案或解析字段 |
| 查看试卷 | 当前发布模拟卷 | 200，按题序返回全部题干，不含选项、答案、解析或评分字段 |
| 查看草稿 | 仅草稿或历史修订的题集 | 404 `SIMULATION_NOT_FOUND` |
| 无目标开考 | 已登录、无 active goal | 422 `LEARNING_GOAL_NOT_ACTIVE`，无写入 |
| 目标版本变化 | 旧 `expectedGoalVersion` | 409 `SIMULATION_GOAL_VERSION_CONFLICT`，无写入 |
| 发布修订变化 | 旧 `expectedRevisionId` | 409 `SIMULATION_REVISION_CHANGED`，无写入 |
| 资格不一致 | 其他资格 active goal | 422 `GOAL_CERTIFICATION_MISMATCH` |
| 多科模拟卷 | 题目来自两个科目 | 列表禁止开考；POST 返回 `SIMULATION_SUBJECT_SCOPE_INVALID` |
| 主观题模拟卷 | 包含 `CASE` 或 `ESSAY` | 列表禁止开考；POST 返回 `SIMULATION_SUBJECTIVE_NOT_SUPPORTED` |
| 链路未开放 | 答题或交卷能力未启用 | 列表 `SIMULATION_NOT_OPEN`；POST 503，不创建会话 |
| 首次开考 | 条件完整且无活动会话 | 创建 `in_progress` 会话，`formalAttemptNo=1`，冻结时长和题目 |
| 同卷恢复 | 同卷已有可恢复会话 | 返回同一会话及原截止时间，不新增会话 |
| 异卷冲突 | 当前目标已有另一卷活动会话 | 409，返回本人原会话恢复路径 |
| 同卷重考 | 上一次会话已 `completed` | 新会话序号递增，历史报告不覆盖 |
| 并发开考 | 两个不同请求号同时开考 | 最多一条活动会话；同卷响应收敛到同一会话 |
| 下架后续考 | 开考后试卷下架 | 本人既有会话使用冻结快照继续；不能新开考 |
| 截止时间 | 客户端时间被修改 | 服务端仍按冻结 `deadlineTime` 自动交卷 |
