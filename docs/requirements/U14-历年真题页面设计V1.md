# U14 历年真题页面设计 V1

> 状态：待实施
> 消费端：学生端「题库 → 历年真题」
> 范围：已发布历年真题题集的查询、查看、练习和考试；不改变首次诊断业务。

## 1. 目标与入口

历年真题页面上方提供筛选，下方展示当前可见的历年真题题集列表。数据唯一来源为：

`cm_collection_current → cm_collection_revision(status='published', collection_type='PAST_PAPER') → cm_collection_item → cm_question_revision`

列表每项展示题集名称、资格、科目、题量、总分、时长和题型，并提供三个入口：`查看`、`练习模式`、`考试模式`。

只读取题集当前已发布修订；草稿、审核中、驳回、历史修订、已下架题集和其他题集类型均不可见、不可开始。

## 2. 题集类型与数据稳定性

### 2.1 新增题集类型

数据库当前没有历年真题类型。新增并统一使用枚举值 `PAST_PAPER`，中文名称为“历年真题”。

该值须同时纳入题集创建、导入预检、题集管理/审核筛选、前端类型定义、服务端类型白名单及数据库约束（如有）的合法值集合；不能只在学生端以题集名称或标签推断真题。

### 2.2 固定题目修订

一份题集修订的每个 `cm_collection_item` 必须固定保存 `question_revision_id`，而不是按题目当前版本查询。发布后不得原地改写该题集修订或其题目引用；题目需要修改时，创建新的题目修订和题集修订，再发布切换。

学生开始练习或考试时，服务端把本次会话关联到该次 `collection_revision_id`；之后即使题集发布了新修订，已开始会话仍使用其开始时冻结的题目版本、题序、分值与时长。

## 3. 三种模式

| 模式 | 用户体验 | 会话与数据处理 |
|---|---|---|
| 查看 | 复用模拟试卷的详情与题干预览，按题序查看题干。 | 只读；不创建会话，不记录作答，不返回正确答案、解析或评分。 |
| 练习模式 | 与知识点练习完全一致：逐题提交，立即显示正误、答案与解析，可继续或结束。 | 创建 `PAST_PAPER` 来源的练习会话；写入错题本、学习记录和能力数据。 |
| 考试模式 | 复用首次诊断的沉浸式答题骨架：倒计时、答题卡、草稿保存、断点续答、主动/超时交卷和结果页。考试期间不显示答案和解析。 | 创建独立的历年真题考试会话；交卷后写入错题本、学习记录和能力数据。 |

## 4. 首次诊断隔离

历年真题考试仅复用首次诊断的前端组件与通用技术能力，不复用首次诊断的领域接口、会话类型、结果处理或报告。

禁止产生下列交集：

- 不读取、不修改首次诊断状态、诊断修订或诊断会话；
- 不触发首次诊断报告、初始画像生成、学习任务生成或 onboarding 流程；
- 不占用首次诊断的并发/恢复约束，也不被首次诊断占用。

历年真题的练习和考试都应以 `PAST_PAPER` 作为错题来源；学习记录需把对应会话来源映射为 `PAST_PAPER`，不能降级为 `OTHER`。

## 5. 页面设计

### 5.1 历年真题列表页

页面由筛选区和题集列表组成。筛选后刷新列表，不影响任何已开始会话。每个题集卡片固定展示三个操作：

- `查看`：打开题干预览弹窗；
- `练习模式`：新建或恢复该题集的练习会话；
- `考试模式`：新建或恢复该题集的考试会话。

同一题集存在未完成会话时，对应按钮改为“继续练习”或“继续考试”。练习会话与考试会话彼此独立，互不覆盖；用户可以先练习同一份真题，再单独发起考试。

### 5.2 查看弹窗

复用模拟试卷的详情弹窗。上方显示题集名称、资格、科目、题量、总分、时长、题型；下方按题序仅显示题号、题型和题干。弹窗底部提供“开始练习”和“考试模式”入口。

查看页不得返回或渲染选项、正确答案、解析、评分、知识点、用户作答和错题状态。

### 5.3 真题练习答题页

该页直接复用知识点练习的答题体验与组件，不额外创造一种答题交互：

- 页面顶部显示题集名称、当前题号和进度，可退出；无正式考试倒计时。
- 客观题选择答案后点击“提交本题”，立即显示正误、正确答案与解析；主观题沿用知识点练习现有的提交和反馈规则。
- 已提交题可通过答题卡回看，但不能修改本次提交结果；未提交题可自由跳转。
- 最后一题提交后可“完成练习”；中途退出时保留会话，并从列表的“继续练习”恢复。
- 每题提交即按知识点练习规则写入作答、错题和能力数据；完成练习只完成会话，不重复计算已提交题。

练习页返回列表路径固定为 `/learning/question-bank/past-papers`，不能跳转到知识点练习目录。

### 5.4 真题考试答题页

该页复用首次诊断的 `FocusExamShell`、答题卡、倒计时、草稿保存与交卷确认交互，但以“历年真题考试”为标题和独立会话运行：

- 顶栏显示题集名称、剩余时间、草稿保存状态和“暂存并退出”；离开后可从“继续考试”恢复。
- 主区一次显示一题，支持上一题、下一题和答题卡跳题；选择题与主观题均只保存草稿，考试中不显示正误、答案或解析。
- 答题卡区显示全部题号和“未作答/已作答”状态，并提供“交卷”。
- 交卷前显示未作答数量确认；交卷成功或时间到后进入真题考试结果页，才显示总分、各题结果、答案和解析。
- 计时、草稿保存、恢复、交卷和超时自动交卷均由服务端会话时间与版本控制，前端时间仅作显示；所有写入请求使用幂等请求号。

### 5.5 真题考试结果页

结果页是独立于首次诊断报告的普通考试结果页，显示本次题集、得分、用时、正确率、各题作答结果和答案解析。提供“返回历年真题”“再练习本卷”“重新考试”入口。

它只写入本次真题考试的学习记录、错题和能力数据；不得出现“首次诊断完成”、初始画像、学习计划或任务推荐等诊断内容。

## 6. 接口与复用边界

- 列表、详情、题干预览：以现有模拟试卷展示接口为结构基底，但服务端查询条件固定为 `collection_type='PAST_PAPER'`。
- 练习：复用知识点练习的答题、逐题判分、解析、错题和能力沉淀规则；题目来源改为指定的已发布真题题集修订，不按知识点抽题。
- 考试：抽取首次诊断中通用的计时、草稿、交卷幂等、会话版本冲突和恢复能力；历年真题使用自己的 `/past-papers/**` 接口、错误码和会话类型。

开始请求必须传入 `expectedRevisionId`。当前发布修订变化时，服务端返回冲突并要求刷新列表；不得悄悄切换到新卷开始作答。

## 7. 筛选与待补数据

首版筛选至少支持资格、科目和关键词。若产品需要“年份/上下午批次”等筛选，必须增加并维护结构化题集元数据（例如 `exam_year`、`exam_session`）；不能从题集名称解析，因为名称可编辑且无法保证准确性。

## 8. 验收要点

1. 只有当前已发布的 `PAST_PAPER` 题集出现在历年真题列表。
2. 查看不产生任何学习、会话或答题记录，且不泄露答案、解析、评分或知识点。
3. 练习模式行为与知识点练习一致，并在错题本、学习记录中标为“历年真题”。
4. 考试模式可计时、保存、恢复与交卷，期间不泄露答案；交卷后沉淀错题、学习记录和能力数据。
5. 历年真题任意操作不改变首次诊断的状态、会话、报告、画像或任务。
6. 已开始的会话始终可还原到开始时的题集修订与题目修订。
7. 练习页即时反馈、逐题提交和完成规则与知识点练习一致；考试页在交卷前不显示答案、解析或正误。
