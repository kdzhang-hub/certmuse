# 学生端统一考试历史后端接口契约 V1

> 状态：已实施。日期：2026-08-20。路由前缀：`/api/learning/history`。
> 本契约替换《学生端学习记录后端接口契约V1》的模拟试卷历史接口，不保留旧路由兼容。

## 1. 目标与边界

统一考试历史按单场会话展示首次诊断、历年真题考试和模拟考试。接口只读取既有会话、冻结题目、作答、评分及报告事实，不写入或修复考试、画像和错题数据。

纳入类型为`initial_diagnosis`、`past_paper_exam`、`simulation`；排除`past_paper_practice`、草稿、取消、无效和未完成会话。旧`/simulations/**`、按逻辑试卷聚合、多次尝试和跨修订比较全部删除。

## 2. 接口定义

两个接口均要求已登录，权限为`certmuse:student`与`certmuse:learning:history:query`的AND；不接受`userId`、请求体或`X-Request-Id`。

### 2.1 考试历史列表

`GET /api/learning/history/exams`

| 参数 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `goalId` | string | 否 | 当前用户拥有的目标；未传时使用唯一活动目标。 |
| `examType` | enum | 否 | `INITIAL_DIAGNOSIS`、`PAST_PAPER`、`SIMULATION`。 |
| `completedFrom` / `completedTo` | date | 否 | `YYYY-MM-DD`，按`Asia/Shanghai`过滤，起始不得晚于结束。 |
| `pageNum` | integer | 否 | 默认1，范围1至10000。 |
| `pageSize` | integer | 否 | 默认10，范围1至100。 |

固定按`completedAt DESC, sessionId DESC`排序。

### 2.2 考试历史详情

`GET /api/learning/history/exams/{sessionId}?goalId=...`

`sessionId`必须为十进制正整数。查询必须同时限制当前`user_id`、选定`goal_id`、允许的会话类型及完成资格；不存在、越权、跨目标、未完成和不支持类型统一返回`HISTORY_EXAM_NOT_FOUND`。

## 3. 成功响应

列表响应：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "rows": [{
      "sessionId": "9001",
      "examType": "PAST_PAPER",
      "title": "2025年系统架构设计师上午真题",
      "subject": {"id": "101", "name": "综合知识"},
      "completedAt": "2026-08-20T10:00:00+08:00",
      "result": {"reportStatus": "AVAILABLE", "score": "45", "maxScore": "75", "scoreRate": 0.6},
      "durationSeconds": 6200,
      "durationLimitSeconds": 7200,
      "durationStatus": "AVAILABLE"
    }],
    "total": 1
  }
}
```

详情在列表字段基础上增加`questions`，按`questionOrder, sessionQuestionId`升序。题目仅包含`questionId`、`questionOrder`、冻结题干摘要、题型、难度、`attemptResult`和分数，不返回原始作答、答案、解析或内部评分过程。

雪花ID使用字符串；时间使用带时区ISO-8601；`score/maxScore`使用十进制字符串；`scoreRate`为0至1的JSON number。集合无数据返回空数组。

## 4. 行为规则

- 初诊要求`submitted_time`非空且状态为`settling/completed`，`completedAt=submitted_time`，标题固定“首次诊断”，`subject=null`。
- 真题和模拟要求`completed + settled_time`，`completedAt=settled_time`，标题读取会话关联的冻结题集修订名称。
- 只有冻结题目全部属于同一个非空科目时返回`subject`；初诊及多科考试返回`null`。
- 报告状态为`AVAILABLE/PROCESSING/FAILED/UNAVAILABLE`；仅`AVAILABLE`返回分数。初诊`settling`且没有报告视为`PROCESSING`；任何`completed`考试缺少对应报告属于`HISTORY_READ_FAILED`。
- `standard`时长要求开始、提交、截止和冻结上限完整且截止等于开始加冻结上限；实际用时为`min(submitted, deadline)-started`。
- `pausable`时长汇总每道会话题首轮尝试的`elapsed_seconds`；所有计时状态必须为`valid`，累计值为正且不超过冻结上限。
- 时长事实不完整或不合法只降级为`durationStatus=UNAVAILABLE`，两个时长数值均为`null`。
- 逐题详情只读取`cm_session_question`冻结快照及对应作答评分事实，不查询当前题库。

## 5. 失败响应

真实HTTP Status必须等于`R.code`。除401/403外使用统一`HistoryErrorVo`：

| HTTP | `errorCode` | 条件 |
|---:|---|---|
| 400 | `HISTORY_REQUEST_INVALID` | 参数、日期、枚举、分页或路径ID不合法。 |
| 404 | `HISTORY_GOAL_NOT_FOUND` | 指定目标不存在或不属于当前用户。 |
| 404 | `HISTORY_EXAM_NOT_FOUND` | 会话不存在、越权、跨目标、未完成或类型不支持。 |
| 422 | `HISTORY_GOAL_REQUIRED` | 未传目标且没有唯一活动目标。 |
| 500 | `HISTORY_READ_FAILED` | 已完成考试缺报告、报告/评分矛盾、必要快照无法解析或查询故障。 |

400、404、422的`traceId=null`；500使用安全文案和非空`traceId`，完整异常只在服务端边界记录一次。

## 6. 安全与可观测性

列表、详情和逐题SQL均显式限制`user_id + goal_id`。日志可记录用户ID、目标ID、`sessionId`、`examType`、分页、结果码和`traceId`，不得记录答案JSON、快照全文、报告JSON或数据库错误细节。

## 7. 验收用例

1. 三类完成考试各返回一行，并按完成时间及会话ID倒序。
2. 三种`examType`过滤准确，`past_paper_practice`和未完成会话不出现。
3. 初诊`settling`且无报告返回`PROCESSING`及空分数。
4. completed缺报告返回500；失败报告返回`FAILED`且空分数。
5. 单科返回冻结科目，多科和初诊返回`subject=null`。
6. standard与pausable合法时长可用，异常计时事实降级为`UNAVAILABLE`。
7. 当前题库修改或下架不影响详情冻结题面。
8. 他人或跨目标`sessionId`统一返回404，不泄露存在性。
