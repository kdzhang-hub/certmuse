# 学习记录练习历史后端接口契约

> 契约版本：V1.0  
> 日期：2026-08-21

## 1. 目标与边界

学习记录按已完成练习会话展示知识点练习和历年真题练习，并增强既有考试历史详情。接口只读取会话冻结快照、当次答案及评分事实，不重新判分、不调用 AI、不返回原始 JSONB 或对象存储路径。

所有接口要求登录用户同时具备 `certmuse:student` 和 `certmuse:learning:history:query` 权限。

## 2. 练习历史列表

```http
GET /api/learning/history/practices
```

查询参数：`goalId` 为字符串雪花 ID；`practiceType` 可为 `KNOWLEDGE_PRACTICE` 或 `PAST_PAPER_PRACTICE`；`completedFrom/completedTo` 为 `YYYY-MM-DD`；`pageNum` 范围 1..10000，`pageSize` 范围 1..100。

日期按 `Asia/Shanghai` 解释为左闭右开的完成时间范围。结果固定按 `completedAt DESC, sessionId DESC` 排序。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "rows": [{
      "sessionId": "900000000000000801",
      "practiceType": "KNOWLEDGE_PRACTICE",
      "title": "知识点练习",
      "subject": {"id": "101", "name": "综合知识"},
      "knowledgePoints": [{"id": "201", "name": "软件架构风格"}],
      "questionCount": 10,
      "answeredCount": 7,
      "correctCount": 5,
      "incorrectCount": 2,
      "unansweredCount": 3,
      "completedAt": "2026-08-20T15:42:10+08:00"
    }],
    "total": 1
  }
}
```

## 3. 练习历史详情

```http
GET /api/learning/history/practices/{sessionId}?goalId=...
```

只允许读取当前用户、选定目标、类型为 `self_practice/past_paper_practice` 且已经结算完成的会话。知识点练习仅返回选择题；历年真题练习可返回 `CHOICE/CASE/ESSAY`。未作答题的 `submission` 为 `null`，评分字段为 `null`，但仍返回冻结正确答案、参考答案和解析。

## 4. 考试历史详情

```http
GET /api/learning/history/exams/{sessionId}?goalId=...
```

练习详情和考试详情的 `questions[]` 均返回完整冻结题面、提交及评分投影。选择题使用 `selectedOptionLabels/correctOptionLabels`；CASE 和 ESSAY 使用 `textAnswer/referenceAnswer`。主观题 AI 成功时返回 `aiFeedback/gradingItems`，处理中或失败时不返回不存在的 AI 结果，失败不得伪装为正常 0 分。

## 5. 失败响应

真实 HTTP Status 等于 `R.code`。401/403 使用平台认证兼容响应；其他失败使用：

```json
{
  "code": 404,
  "msg": "练习历史不存在",
  "data": {
    "errorCode": "HISTORY_PRACTICE_NOT_FOUND",
    "retryable": false,
    "traceId": null,
    "fieldErrors": [],
    "details": null
  }
}
```

| HTTP | errorCode | 触发条件 | retryable |
|---:|---|---|:---:|
| 400 | `HISTORY_REQUEST_INVALID` | ID、枚举、日期或分页参数非法 | false |
| 404 | `HISTORY_GOAL_NOT_FOUND` | 指定目标不属于当前用户 | false |
| 404 | `HISTORY_PRACTICE_NOT_FOUND` | 会话不存在、越权、跨目标、未完成或类型不符 | false |
| 422 | `HISTORY_GOAL_REQUIRED` | 未指定目标且不存在唯一活动目标 | false |
| 500 | `HISTORY_READ_FAILED` | 快照、评分或统计事实损坏 | false |

400 的 `fieldErrors[]` 包含 `field/code/message`，code 使用 `REQUIRED`、`INVALID_FORMAT` 或 `OUT_OF_RANGE`。4xx 的 `traceId` 默认为 `null`；500 必须返回非空 `traceId`，响应不包含内部原因。

## 6. 安全与验收

- 所有雪花 ID 以字符串返回，分数以十进制字符串返回，得分率为 0..1 JSON number。
- 不记录题干、选项、用户答案、正确答案、解析、AI 反馈、量规或完整响应。
- 当前题库修订、下架或知识树改名不得改变历史结果。
- 列表满足 `questionCount=answeredCount+unansweredCount` 和 `answeredCount=correctCount+incorrectCount`。
- 越权、跨目标、未完成及不支持类型的练习详情均返回相同 404。
