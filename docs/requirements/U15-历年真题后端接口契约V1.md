# U15 历年真题后端接口契约 V1

> 2026-08-20 起，本文件第 2.4–2.5 节中仅“练习模式”的接口形状与行为，改由 [U15-历年真题练习模式后端接口契约V1.md](U15-历年真题练习模式后端接口契约V1.md) 定义；列表、预览、答案预览和正式考试模式仍以本文件为准。

> 契约版本：V1.0
> 状态：待实施
> 路由前缀：`/api/assessment/past-papers`
> 消费端：学生端「题库 → 历年真题」及其查看、练习、考试、结果页。

## 1. 目标与边界

本契约提供当前学习目标范围内已发布历年真题的列表、只读题干预览、练习会话和正式考试会话。

题集来源固定为：

`cm_collection_current → cm_collection_revision → cm_collection_item → cm_question_revision`

仅当 `cm_collection_revision.status='published'`、`collection_type='PAST_PAPER'`，且 `cm_collection_current.collection_revision_id` 指向该修订时，学生端才可读取或开始。草稿、审核中、驳回、已被新修订替代的旧修订、下架题集及其他类型统一不可见。

- **查看**只返回题号、题型与题干，不创建会话，不返回选项、答案、解析、评分、知识点或用户数据。
- **练习**复用知识点练习的逐题提交、即时判分、答案解析、错题和能力沉淀规则，但题单固定来自指定题集修订，不按知识点选题。
- **考试**复用首次诊断的计时、草稿、答题卡、恢复、交卷和超时技术能力；它使用独立会话、接口、结果和数据结算，绝不读取或改变首次诊断状态、报告、画像初始化或任务生成。

V1 仅允许所有题目均为可同步判分 `CHOICE` 的真题题集进入练习和考试。包含 `CASE`、`ESSAY` 或冻结数据不完整的题集仍可查看题干，练习和考试返回不可用状态；主观题正式评分另行冻结契约。

## 2. 数据与接口定义

### 2.1 实施前置与迁移

迁移必须新建在 `backend/script/sql/postgres/certmuse/`，不得改写已部署迁移，并在部署前审计历史数据。

1. `cm_collection`、`cm_collection_revision`、`cm_paper_import` 的题集类型检查约束增加 `PAST_PAPER`；服务端题集创建/查询和导入白名单、管理端 `CollectionType` 联合类型及中文映射同步增加该值。
2. `ck_cm_learning_session_session_type` 增加 `past_paper_practice` 与 `past_paper_exam`。二者均要求 `collection_revision_id` 非空；`past_paper_exam` 还要求 `timing_mode='standard'`、正的 `duration_seconds_snapshot`、`deadline_time > started_time`、正的 `formal_attempt_no`。
3. 增加以下唯一索引。练习与考试模式按同一修订独立，因此互不阻塞；不同题集也可各自恢复。

```sql
CREATE UNIQUE INDEX uk_cm_learning_session_active_past_paper_practice
    ON cm_learning_session(user_id, goal_id, collection_revision_id)
    WHERE session_type='past_paper_practice'
      AND status IN ('created','in_progress');

CREATE UNIQUE INDEX uk_cm_learning_session_active_past_paper_exam
    ON cm_learning_session(user_id, goal_id, collection_revision_id)
    WHERE session_type='past_paper_exam'
      AND status IN ('created','in_progress','submitted','settling');

CREATE UNIQUE INDEX uk_cm_learning_session_past_paper_exam_attempt
    ON cm_learning_session(user_id, goal_id, collection_revision_id, formal_attempt_no)
    WHERE session_type='past_paper_exam';
```

4. 错题来源映射增加：`past_paper_practice`、`past_paper_exam → PAST_PAPER`；错题筛选 `source` 白名单接受 `PAST_PAPER`。学习记录映射增加：上述两种会话类型均为 `PAST_PAPER`，不得返回 `OTHER`。
5. 创建任一会话时，按 `cm_collection_item.item_order ASC` 将每题的 `question_id`、`question_revision_id`、题序、分值、题面、评分、知识点与评分点写入 `cm_session_question` 冻结快照；不得在后续读取、判分或结果页回查当前题库。

### 2.2 公共约定

游客可匿名调用列表、详情和题面预览接口；`setup` 在匿名时只返回可浏览资格和科目，在登录时额外返回当前目标。创建会话、作答、答案解析、结果、学习记录与全部写入接口仍要求登录学习账号、`certmuse:student` 和对应隐藏权限：查询/预览以外的读取和写入按既有 `certmuse:assessment:past-paper:query` / `certmuse:assessment:past-paper:answer` 权限执行。服务端从登录态取得 `userId` 和当前 `active` 目标；客户端不得传入或覆盖用户、目标、题目版本、正确答案、评分或画像数据。

ID 均为十进制正整数字符串；时间为带时区 ISO-8601，业务展示时区为 `Asia/Shanghai`。真实 HTTP Status 必须等于 `R.code`。全部 POST 均要求 `X-Request-Id`：标准 UUID，服务端以小写 36 字符规范化；同一用户、动作和规范化载荷在 24 小时内回放首次成功结果。

除 401/403 外，失败统一为：

```json
{"code":409,"msg":"题集已更新","data":{"errorCode":"PAST_PAPER_REVISION_CHANGED","retryable":true,"traceId":null,"fieldErrors":[],"details":null}}
```

400 的字段错误仅使用 `REQUIRED`、`INVALID_FORMAT`、`OUT_OF_RANGE`，路径使用 camelCase 请求字段名；4xx 的 `traceId=null`；5xx 使用安全文案和非空 `traceId`。前端只按 `errorCode` 分支。

### 2.3 列表、详情和题干预览

```http
GET /api/assessment/past-papers/setup
GET /api/assessment/past-papers?certificationId={id}&subjectId={id}&keyword={text}&pageNum=1&pageSize=20
GET /api/assessment/past-papers/{collectionId}
GET /api/assessment/past-papers/{collectionId}/preview
```

`setup` 返回登录用户的当前目标 `{ certificationId, certificationName, version }`（游客为 `null`）和可筛选资格/科目。游客首次进入必须自行选择浏览资格，浏览资格与位置只保留在浏览会话，不写入账户。列表查询参数均可选：`certificationId`、`subjectId` 为正整数；`keyword` 去首尾空格后为 1–100 字符；`pageNum` 默认 1、最小 1；`pageSize` 默认 20、范围 1–100。固定按最近 `published_time DESC, collectionId DESC` 排序。

列表成功响应：

```json
{"code":200,"msg":"操作成功","data":{"rows":[{"collectionId":"901","revisionId":"902","collectionName":"2025年系统架构设计师综合知识真题","certificationName":"系统架构设计师","subject":{"id":"903","name":"综合知识"},"questionCount":75,"totalReportScore":"75","durationMinutes":150,"questionTypes":["CHOICE"],"practiceAccess":{"action":"START","canStart":true,"blockCode":null},"examAccess":{"action":"START","canStart":true,"blockCode":null}}],"total":1}}
```

`action` 为 `START`、`RESUME` 或 `BLOCKED`。登录用户在当前有效学习目标下有同一真题修订的 `past_paper_exam` 活动会话（`created`、`in_progress`、`submitted` 或 `settling`）时，该行的 `examAccess.action` 返回 `RESUME`；再次调用开始考试接口必须复用该会话，不创建第二场考试。详情返回列表字段加 `rules`；预览返回 `{ collectionId, revisionId, questions:[{questionOrder,questionType,stem,options,images}] }`。游客预览仅返回阅读题面所需的题干、选项和受控图片 URL；严禁返回答案、解析、知识点、评分、会话或错题状态。

`collectionId` 必须是正整数。详情和预览只接受当前已发布 `PAST_PAPER`；不存在、类型不符、非当前修订或无权可见时统一返回 404 `PAST_PAPER_NOT_FOUND`。

### 2.4 开始或恢复会话

```http
POST /api/assessment/past-papers/{collectionId}/practice-sessions
POST /api/assessment/past-papers/{collectionId}/exam-sessions
Content-Type: application/json
X-Request-Id: 0f7cd9a8-4b29-4ba5-b202-b7fb5aac85dd
```

请求体：

```json
{"expectedRevisionId":"902","expectedGoalVersion":4}
```

`expectedRevisionId` 为当前列表返回的正整数；`expectedGoalVersion` 为 `setup` 返回的非负整数。规范化载荷分别为 `past_paper_practice_start/1.0`、`past_paper_exam_start/1.0`，至少包含 `userId`、`collectionId`、`expectedRevisionId`、`expectedGoalVersion`。

同一事务依次校验当前有效目标、目标版本、题集当前发布修订、题目资格、唯一已发布规则版本和已有活动会话；随后创建会话与全量 `cm_session_question` 快照，并写入幂等成功响应。练习会话为 `past_paper_practice`、无计时；考试会话为 `past_paper_exam`、启动时冻结题集时长、开始时间、截止时间和本修订下一次 `formal_attempt_no`。任一步失败必须回滚，不能遗留半份题单或活动会话。

同一用户、目标、题集修订、模式已有活动会话时不创建第二份，而是返回该会话，`action='RESUME'`。练习和考试即使属于同一题集也不互相恢复或覆盖。开始响应：

```json
{"code":200,"msg":"操作成功","data":{"sessionId":"904","totalCount":75,"action":"START","answerPath":"/learning/session/past-paper-practice?sessionId=904"}}
```

考试的 `answerPath` 为 `/learning/session/past-paper-exam?sessionId=904`。请求修订与当前修订不一致返回 409 `PAST_PAPER_REVISION_CHANGED`，不得自动切换新修订。

### 2.5 练习作答接口

```http
GET  /api/assessment/past-papers/practice-sessions/{sessionId}
GET  /api/assessment/past-papers/practice-sessions/{sessionId}/items/{questionOrder}
POST /api/assessment/past-papers/practice-sessions/{sessionId}/items/{questionOrder}/submit
POST /api/assessment/past-papers/practice-sessions/{sessionId}/complete
```

仅接受当前用户的 `past_paper_practice` 会话，否则 404 `PAST_PAPER_PRACTICE_SESSION_NOT_FOUND`。首次读取 `created` 会话时原子转为 `in_progress`。会话读模型返回题序导航、已提交状态和返回路径 `/learning/question-bank/past-papers`；题目读模型在提交前只返回冻结题面，在提交后返回 `{ selectedOptionLabels, correct, correctOptionLabels, analysis }`。

单题提交体为 `{"answer":{"value":["A"]}}`。单选恰含一个冻结选项，多选为非空、去重且全部属于冻结选项的数组。服务端按冻结评分快照同步判分；同一题只可提交一次。提交在同一事务写入 attempt、answer、错误事实及能力证据，错题来源固定为 `PAST_PAPER`。未提交题不产生任何作答或能力数据。

`complete` 无请求体。它将活动会话推进为 `completed`；未提交题不视为跳过或错误。提交与结束操作均要求 `X-Request-Id`，重复请求按首次结果回放。

### 2.6 考试作答、草稿和结果接口

```http
GET  /api/assessment/past-papers/exam-sessions/{sessionId}
GET  /api/assessment/past-papers/exam-sessions/{sessionId}/items/{questionOrder}
PUT  /api/assessment/past-papers/exam-sessions/{sessionId}/items/{questionOrder}/draft
POST /api/assessment/past-papers/exam-sessions/{sessionId}/timer-events
GET  /api/assessment/past-papers/exam-sessions/{sessionId}/finish-check
POST /api/assessment/past-papers/exam-sessions/{sessionId}/finish
GET  /api/assessment/past-papers/exam-sessions/{sessionId}/result
```

除结果外，仅接受当前用户的活动 `past_paper_exam` 会话，否则 404 `PAST_PAPER_EXAM_SESSION_NOT_FOUND`。会话读取返回服务器确认的 `deadlineTime`、`remainingSeconds`、`sessionVersion`、题序导航和草稿状态；前端倒计时只展示服务器事实。未交卷题目读取只能返回冻结题面和本人的草稿，绝不返回正误、答案、解析、评分或错题状态。

`draft` 和 `timer-events` 均要求 `X-Request-Id` 与 `expectedSessionVersion`。草稿体为 `{"answer":{"value":["A"]},"expectedSessionVersion":7}`；保存成功返回递增后的 `sessionVersion`。计时事件只接受 `ENTER`、`HEARTBEAT`、`HIDDEN`、`LEAVE`，客户端不得上传剩余时间、累计时长或评分数据。版本冲突返回 409 `PAST_PAPER_EXAM_SESSION_VERSION_CONFLICT`，前端重新读取会话，不覆盖服务器草稿。

`finish-check` 返回 `{ sessionVersion, unansweredCount, totalCount, deadlineTime, canFinish }`。`finish` 请求体为 `{"expectedSessionVersion":7}`，要求 `X-Request-Id`。服务端锁定会话，按冻结快照将草稿转为最终作答，并原子完成同步判分、错题与能力结算；空白题按考试规则记录为未作答，不在交卷前泄露正确答案。时间到时服务端以相同结算路径自动交卷；人工交卷与自动交卷竞争时只允许一个成功结算，另一方回放或返回最终状态。

结果接口只允许已完成会话，返回题集、得分、满分、用时、各题冻结题面（含题干、选项和受控图片）、作答结果、正确答案和解析；图片只返回可访问 URL、排序与替代文本，不返回存储路径或对象键。结果页路径固定为 `/learning/result/past-paper-exam?sessionId={sessionId}`。它不是首次诊断报告，禁止返回或触发诊断、初始画像、任务或 onboarding 字段。

### 2.7 失败响应

| 接口 | HTTP | errorCode | 触发条件 | retryable | 前端行为 |
|---|---:|---|---|---:|---|
| 全部 | 400 | `PAST_PAPER_REQUEST_INVALID` | ID、分页、筛选、请求体、版本或请求号格式不合法 | false | 按字段错误修正，不盲目重试 |
| 全部 | 401/403 | 认证兼容格式 | 未登录、非学生或缺少权限 | false | 按既有登录/无权限流程处理 |
| 列表/开始 | 409 | `LEARNING_GOAL_NOT_ACTIVE` | 无当前有效目标 | false | 引导设置学习目标 |
| 开始 | 409 | `PAST_PAPER_GOAL_VERSION_CONFLICT` | 当前目标版本变化 | true | 刷新 setup 和列表 |
| 详情/预览/开始 | 404 | `PAST_PAPER_NOT_FOUND` | 不存在、非真题、非当前已发布修订或不可见 | false | 返回列表并刷新 |
| 开始 | 409 | `PAST_PAPER_REVISION_CHANGED` | `expectedRevisionId` 过期 | true | 刷新列表，不自动开考 |
| 开始 | 422 | `PAST_PAPER_UNSUPPORTED_QUESTION_TYPE` | 含非 CHOICE 题 | false | 保留查看，禁用练习/考试 |
| 开始 | 422 | `PAST_PAPER_UNAVAILABLE` | 空卷、题序/时长/快照或题集数据不合法 | false | 提示题集维护中 |
| POST | 409 | `PAST_PAPER_IDEMPOTENCY_CONFLICT` | 请求号对应不同用户、动作或规范化载荷 | false | 新请求号仅用于重新发起的用户操作 |
| 练习接口 | 404 | `PAST_PAPER_PRACTICE_SESSION_NOT_FOUND` | 会话不存在、非本人或类型不符 | false | 返回真题列表 |
| 考试接口 | 404 | `PAST_PAPER_EXAM_SESSION_NOT_FOUND` | 会话不存在、非本人或类型不符 | false | 返回真题列表 |
| 考试写入 | 409 | `PAST_PAPER_EXAM_SESSION_VERSION_CONFLICT` | 草稿或交卷使用旧会话版本 | true | 重新读取服务器会话 |
| 练习提交 | 409 | `PAST_PAPER_PRACTICE_ITEM_ALREADY_SUBMITTED` | 同题已提交 | false | 刷新当前题结果 |
| 考试结果 | 409 | `PAST_PAPER_EXAM_NOT_FINISHED` | 考试尚未完成 | true | 留在答题页或轮询状态 |
| 全部 | 500 | `PAST_PAPER_SYSTEM_FAILURE` | 未预期查询、快照、判分或结算故障 | true | 保留页面状态，显示 traceId |

## 3. 成功响应与状态规则

所有列表的 `total` 是过滤后的逻辑题集数，分页后返回；题目、导航、选项和结果题目固定按冻结题序升序。数值分数使用 JSON 字符串，避免浮点精度漂移。`questionRevisionId`、答案、解析、评分和知识点仅在已开始会话的冻结快照中使用，不作为查看接口字段。

考试草稿仅保存于本次会话，不生成 attempt、错题或能力数据。练习提交和考试交卷后，均按冻结知识点映射沉淀能力；同一次重试不得重复建错题或重复结算。真题考试的结果、错题和学习记录可见，但不改变首次诊断或其派生数据。

## 4. 安全与可观测性

- 游客列表、详情和预览只读取资格启用、当前修订且已发布的 `PAST_PAPER`；其余查询条件必须同时绑定登录用户、当前目标、会话类型和资源 ID；不得先按 ID 查询后再在应用层判断所有权。
- 预览、活动考试题目和日志不得泄露正确答案、解析、评分或完整题面快照；考试交卷前不得通过任何接口推断对错。
- 日志只记录用户 ID、目标 ID、题集/修订/会话 ID、模式、题量、结果码、请求号和 traceId；不记录题干、选项、答案、解析、草稿或完整快照。
- 当前发布修订变化只影响新的开始请求；已存在会话始终以 `collection_revision_id` 和 `cm_session_question` 快照还原。

## 5. 验收用例

1. 游客和登录用户均只看到当前已发布 `PAST_PAPER` 修订；草稿、旧修订、模拟卷及专项题集均不可见。
2. 游客查看和预览不创建会话，仅返回题干、选项、受控图片和题集元数据，不返回答案、解析、知识点、评分或个人数据。
3. 同卷可同时存在练习会话和考试会话；各自恢复、结束和数据写入互不影响。
4. 开始后发布新修订，旧会话题目、题序、分值、时长、答案和解析仍取旧快照；新开始请求使用旧 revisionId 时返回版本冲突。
5. 练习提交后立即反馈，错误题进入错题本且来源为 `PAST_PAPER`；学习记录来源也是 `PAST_PAPER`。
6. 考试期间保存草稿、跳题、恢复与刷新均不泄露对错；交卷或超时后才出现答案解析和结果。
7. 考试的任何开始、保存、交卷、超时与结果读取均不读取或改变首次诊断会话、报告、画像初始化和任务。
8. 重复 POST 使用相同请求号与载荷精确回放；不同载荷使用相同请求号返回幂等冲突；并发交卷只产生一次最终结算。
9. 含 CASE/ESSAY、空卷、非法题序、无时长或快照不完整的题集可以查看但不可练习、不可考试。
10. 401/403、400 字段错误、404 不可见资源、409 版本/会话冲突、422 题集门禁和 500 均遵守本契约响应结构。
