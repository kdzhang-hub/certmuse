# U11 今日任务执行与答题后端接口契约 V1

```yaml
contract_id: learner-daily-task-execution-u11
contract_version: 1.0
module: U11
routes:
  - /api/learning/tasks/{taskId}/learning-content
  - /api/learning/tasks/{taskId}/start-practice
  - /api/assessment/daily-tasks/{sessionId}
  - /api/assessment/daily-tasks/{sessionId}/items/{questionOrder}
  - /api/assessment/daily-tasks/{sessionId}/items/{questionOrder}/submit
  - /api/assessment/daily-tasks/{sessionId}/complete
scope: learner-daily-task-execution
status: handoff_ready
updated_at: 2026-08-17
depends_on:
  - U10-今日任务展示页后端接口契约V1.2
  - U09-知识点练习答题页后端接口契约V1.1
```

## 1. 范围与 U10 对齐规则

本契约只定义 U10 V1.2 启动后的任务执行，不替代 U10 的任务列表、启动、补充、任务池、任务项完成推导或错误码。

每项任务固定包含两个必需且有序的 `cm_task_item`：

1. `知识点学习`：先展示冻结教材；不可跳过。
2. `知识点练习`：从合格题中冻结 `1–8` 道单选 `CHOICE` 题。

页面固定显示“教材学习”“题目训练”两个不可点击的步骤标签。启动后先进入教材学习；只有点击“题目训练”并成功完成学习项后才能进入答题区。答题区不能返回教材学习。全部冻结题均成功形成 `submitted` 有效提交后，才显示“完成任务”；用户点击后完成练习项并返回任务列表。

任务本身不保存或更新完成状态。学习项与练习项各自存在一条 `cm_task_attempt(attempt_no=1)`；两个事实都为 `completed` 时，任务是否完成由 U10 实时推导。

生成任务时必须至少选出 1 道合格单选题；没有合格题时不得创建空任务。单个任务题量最多 8 道。

本期不包含 CASE、ESSAY、AI 评分、AI 回调、结果页、提前结束、跳过学习或跳过题目。

## 2. 公共约定

所有接口返回 `R<T>`，实际 HTTP 状态等于 `R.code`。所有接口均要求 `certmuse:student` 与 `certmuse:assessment:daily-task:answer` 权限；U10 `launch` 仍使用其自身的 `certmuse:learning:task:launch` 权限。

`taskId`、`sessionId`、`questionOrder` 是十进制正整数并以字符串传输；格式或范围错误返回 400 `TASK_REQUEST_INVALID`。所有 POST 需要 `X-Request-Id`：标准 UUID、小写规范化、24 小时幂等回放。相同动作与相同规范化载荷回放成功响应；不同载荷返回 409 `TASK_IDEMPOTENCY_CONFLICT`；并发请求等待首次事务完成或回滚。

非本人、非当前目标或不存在的任务统一返回 404 `TASK_NOT_FOUND`；会话不存在、非本人或不是 `daily_task` 会话统一返回 404 `TASK_SESSION_NOT_FOUND`。4xx 的 `traceId=null`；未知 500 返回非空 `traceId`。字段错误码仅使用 `REQUIRED`、`INVALID_FORMAT`、`OUT_OF_RANGE`。

教材和题目均只读取任务创建时冻结的内容。图片只冻结对象标识、替代文字和排序，响应 URL 由 OSS 抽象临时生成；不得返回题库当前修订、画像快照或临时签名 URL。

## 3. 教材学习

### 3.1 读取教材

```http
GET /api/learning/tasks/{taskId}/learning-content
```

U10 `launch` 返回 `nextAction='OPEN_LEARNING_CONTENT'` 且 `sessionId=null` 时，前端调用本接口。接口返回该任务学习项的冻结教材，不返回题目、答案、解析或评分点。

```ts
interface DailyTaskLearningContentVo {
  taskId: string;
  phase: 'LEARNING';
  title: string;
  knowledgePoint: string;
  estimatedMinutes: number;
  sections: Array<{
    order: number;
    title: string;
    content: string;
    images: Array<{ url: string; alt: string | null; sortOrder: number }>;
  }>;
  nextAction: 'START_PRACTICE';
}
```

教材项使用 `target_data` 冻结 schema `daily_task_learning_content/1.0`，至少含 `schema_version`、标题、正文区块、图片对象标识、替代文字与稳定排序。区块按 `order ASC`，图片按 `sortOrder ASC` 再按冻结稳定标识排序。

```json
{
  "schema_version": "daily_task_learning_content/1.0",
  "title": "架构风格专项学习",
  "knowledgePoint": "架构风格",
  "sections": [{
    "order": 1,
    "title": "分层架构",
    "content": "……",
    "images": [{
      "stableId": "1950000000000000201",
      "storagePath": "textbook/architecture/layered.png",
      "altText": "分层架构示意图",
      "sortOrder": 1
    }]
  }]
}
```

`storagePath`、`stableId` 仅存在于冻结快照，不通过接口返回。响应中的 `url` 使用 OSS 抽象按请求临时生成。

### 3.2 完成学习并进入题目训练

```http
POST /api/learning/tasks/{taskId}/start-practice
X-Request-Id: <uuid>
```

请求无 body。服务端锁定当前目标、该任务内部会话和任务后，复核学习项未跳过且教材可用；将学习项的唯一 `cm_task_attempt` 标记为 `completed`。随后读取 U10 首次启动时已创建的同一 `daily_task` 会话，创建或恢复练习项的 `cm_task_attempt`，将该会话转为 `in_progress`，返回答题页所需会话 ID。

同一请求重试或学习项已完成后重复点击，不重复写学习完成事实，均返回同一可恢复练习会话。其他任务占用当前目标时，沿用 U10 的 409 `TASK_SESSION_IN_PROGRESS` 和 `details.currentTaskId/nextAction/sessionId`；无可恢复会话时沿用 `TASK_SESSION_NOT_RECOVERABLE`。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "taskId": "1950000000000000001",
    "sessionId": "1950000000000000101",
    "nextAction": "OPEN_PRACTICE_SESSION"
  }
}
```

## 4. 题目训练

### 4.1 获取会话摘要

```http
GET /api/assessment/daily-tasks/{sessionId}
```

仅允许 `in_progress`、`submitted`、`settling`、`completed` 会话读取；不再通过首次读取改变状态。`in_progress` 返回题目导航，其他状态只返回下一步动作。

```ts
interface DailyTaskSessionVo {
  sessionId: string;
  taskId: string;
  sessionStatus: 'IN_PROGRESS' | 'ALL_SUBMITTED' | 'COMPLETED';
  totalCount: number; // 1..8
  submittedCount: number;
  navigation: Array<{ questionOrder: number; state: 'SUBMITTED' | 'UNANSWERED' }>;
  nextAction: 'CONTINUE_PRACTICE' | 'COMPLETE_TASK' | 'RETURN_TASKS';
  returnPath: string | null;
}
```

`submitted` 映射为 `ALL_SUBMITTED`，`settling` 仅在确认请求的事务内使用，不对摘要暴露。`completed` 不返回题目导航或题目内容。

### 4.2 按需读取单题

```http
GET /api/assessment/daily-tasks/{sessionId}/items/{questionOrder}
```

仅允许 `in_progress` 会话读取第 `1..totalCount` 题。题目从 `cm_session_question` 冻结快照投影，且必须为单选 `CHOICE`。未提交题不返回正确答案、解析或用户历史记录；已提交题返回本会话已选答案、对错、正确答案和冻结解析。

```ts
interface DailyTaskItemVo {
  sessionId: string;
  questionOrder: number;
  totalCount: number; // 1..8
  question: {
    questionType: 'CHOICE';
    selectionMode: 'single';
    stem: string;
    options: Array<{ label: string; content: string }>;
    images: Array<{ url: string; alt: string | null; sortOrder: number }>;
  };
  submission: null | {
    selectedOptionLabels: [string];
    correct: boolean;
    correctOptionLabels: [string];
    analysis: string | null;
  };
}
```

### 4.3 提交单题

```http
POST /api/assessment/daily-tasks/{sessionId}/items/{questionOrder}/submit
X-Request-Id: <uuid>
Content-Type: application/json

{ "answer": { "value": ["A"] } }
```

提交只允许一个有效选项标签。服务端锁定会话后，以冻结答案同步判分，在同一事务内写入该 `cm_session_question` 唯一 `cm_question_attempt(attempt_no=1)`、唯一 `cm_attempt_answer` 和题目提交事实。答对与答错均为有效提交；`completedQuestionCount` 只按本任务会话的有效 `submitted` attempt 计数。

提交成功立即返回当前题的已选答案、对错、正确答案、冻结解析和最新 `submittedCount`。同题已提交返回 409 `TASK_ITEM_ALREADY_SUBMITTED`；最后一题提交后会话转为 `submitted`，前端不再显示题目提交入口，只显示“完成任务”。

```ts
interface SubmitDailyTaskItemVo {
  questionOrder: number;
  submittedCount: number;
  submission: {
    selectedOptionLabels: [string];
    correct: boolean;
    correctOptionLabels: [string];
    analysis: string | null;
  };
}
```

每日任务答题与 U09 使用同一同步结算规则：答错写入错题事实；答对与答错均写入结算与学习证据，并更新知识点、父级、科目及总体画像。上述写入与题目提交和幂等成功响应处于同一事务，任一步失败全部回滚。

## 5. 完成任务

```http
POST /api/assessment/daily-tasks/{sessionId}/complete
X-Request-Id: <uuid>
```

仅当 `submittedCount=totalCount` 时允许调用。服务端锁定会话与练习项，确认学习项已完成、全部冻结题均为有效 `submitted`，将练习项唯一 `cm_task_attempt` 标记为 `completed`，并依 U10 的完成事实推导任务完成。会话按既有状态机 `submitted → settling → completed` 推进；不更新 `cm_learning_task.status`，不创建 CASE/ESSAY/AI 评分或额外结果页。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "taskId": "1950000000000000001",
    "sessionId": "1950000000000000101",
    "nextAction": "RETURN_TASK_LIST"
  }
}
```

未完成全部冻结题返回 409 `TASK_NOT_ALL_SUBMITTED`；已完成会话以幂等回放返回相同成功响应；`invalid/cancelled` 会话沿用 U10 `TASK_SESSION_NOT_RECOVERABLE`。

## 6. 幂等动作与失败响应

三个 POST 的 `action_code` 和规范化载荷固定如下：

| 动作 | action_code | 规范化载荷 |
|---|---|---|
| 完成学习并开始练习 | `START_DAILY_TASK_PRACTICE` | `userId + taskId` |
| 提交单题 | `SUBMIT_DAILY_TASK_ITEM` | `userId + sessionId + questionOrder + answer.value` |
| 完成任务 | `COMPLETE_DAILY_TASK` | `userId + sessionId` |

提交和完成的成功幂等响应以 `daily_task_action_idempotency/1.0` 持久化，`schema_version` 由服务端版本化 JSON 工厂写入；回放仅返回其 `response.data`，不向 HTTP 响应暴露内部幂等文档。

| HTTP | errorCode | 条件 |
|---:|---|---|
| 400 | `TASK_REQUEST_INVALID` | ID、请求头或请求体格式非法 |
| 404 | `TASK_NOT_FOUND` | 任务不存在、非本人或不属于当前目标 |
| 404 | `TASK_SESSION_NOT_FOUND` | 会话不存在、非本人、非当前目标或不是 `daily_task` |
| 404 | `TASK_ITEM_NOT_FOUND` | 当前会话不存在该题序号 |
| 409 | `TASK_SESSION_IN_PROGRESS` | 其他任务占用当前目标 |
| 409 | `TASK_SESSION_NOT_ACTIVE` | 会话存在但当前状态不允许所请求的答题动作 |
| 409 | `TASK_SESSION_NOT_RECOVERABLE` | 会话为 `invalid/cancelled` 或内部会话不可恢复 |
| 409 | `TASK_ITEM_ALREADY_SUBMITTED` | 同题已有不同请求形成的有效提交 |
| 409 | `TASK_NOT_ALL_SUBMITTED` | 尚有冻结题未提交 |
| 409 | `TASK_IDEMPOTENCY_CONFLICT` | 请求号载荷冲突或幂等记录不可回放 |
| 422 | `TASK_ANSWER_INVALID` | 不是唯一有效单选选项 |
| 500 | `TASK_OPERATION_FAILED` | 未知异常 |

所有预期 4xx 的 `retryable=false`、`traceId=null`；`TASK_SESSION_IN_PROGRESS` 的 details 沿用 U10。未知 500 的 `retryable=true` 且返回非空 `traceId`。

## 7. 验收

1. U10 首次启动返回 `OPEN_LEARNING_CONTENT` 与空会话 ID；教材接口按 `taskId` 返回冻结资料。
2. 教材不可跳过；只有 `start-practice` 成功后才有练习 `sessionId`，答题接口拒绝学习阶段会话。
3. 练习会话冻结 `1–8` 道合格单选题；没有合格题时不得创建任务；任意一题未提交时不显示或允许完成任务。
4. 选择题答对、答错均计入有效提交；全部冻结题提交后才显示“完成任务”。
5. 完成任务仅写练习项完成事实；学习项和练习项均完成后，任务从 U10 列表自然消失，任务表不写业务状态。
6. 同任务重复启动、教材阶段重复点击、跨设备重复提交和重复完成均不产生第二个学习完成事实、会话、题目作答或练习完成事实。
7. 教材与题目图片只冻结对象事实，响应临时 URL 不写回快照；每日任务答案与 U09 一样完成错题和全层级画像结算。
