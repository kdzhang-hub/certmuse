# 学习记录：题目历史改为练习历史改造方案

> 状态：待实施  
> 日期：2026-08-21  
> 页面：`web/student/src/views/student/history/index.vue`  
> 后端路由前缀：`/api/learning/history`  
> 范围：学习记录只读查询与学生端展示，不改变练习、考试、评分、错题或画像的写入规则。

## 1. 改造结论

将学习记录页的“题目历史”改成“练习历史”，列表不再按 `question_id` 聚合，而是每行对应一次已经结束的练习会话：

- 知识点练习：`cm_learning_session.session_type='self_practice'`；
- 历年真题练习：`cm_learning_session.session_type='past_paper_practice'`；
- 只显示 `status='completed'` 且 `settled_time` 非空的会话；
- 每次会话详情按冻结题序展示完整选择题题面、全部选项、用户当时选择、冻结正确答案、题库解析、对错及得分；
- “完成日期”列表只显示 `YYYY-MM-DD`，详情可以保留完整完成时间；日期筛选仍按 `Asia/Shanghai` 解释。

练习模式当前不会出现 `CASE`、`ESSAY`，本次不扩展知识点练习或历年真题练习的题型和作答链路。案例题、论文题的历史作答、AI 评分及解析只改造现有“考试历史详情”，数据来源是正式考试已经保存的主观题事实。

## 2. 已核对的现状和数据边界

### 2.1 当前页面和学习记录接口

学生端学习记录页面当前有“每日任务、题目历史、考试历史”三个页签。“题目历史”调用：

- `GET /api/learning/history/questions`
- `GET /api/learning/history/questions/{questionId}`

后端 `LearningHistoryMapper.xml` 的 `questionAggregate` 会把当前目标下所有有效作答按 `question_id` 聚合，不限于知识点练习和真题练习。它会把每日任务、练习、考试、订正等不同会话中的同一道题合并，因此无法表达“哪一次练习做了哪些题”。

当前详情只返回 `answerSummary`，选择题最多显示“选择 A”，不返回选项内容和冻结正确答案；考试详情只返回题干摘要、结果和分数，不返回当次答案、正确答案、题库解析或主观题 AI 评分。

### 2.2 数据库中已经存在的事实

本方案依据现有迁移和 Mapper 核对，不把尚未存在的字段描述为现状。

本机 PostgreSQL 服务存在，但本轮没有可用的数据库认证上下文，因此没有读取实际用户答案或统计生产/本地业务行数。下述结构结论来自仓库中的已实施迁移、写入 SQL 和 Java 读写代码；目标环境实际迁移状态必须在部署前执行第 6.3 节只读 SQL 再确认。

| 事实 | 现有表/字段 | 用途 |
| --- | --- | --- |
| 会话所有者、目标、类型、状态和时间 | `cm_learning_session.user_id/goal_id/session_type/status/started_time/submitted_time/settled_time` | 列表、权限、完成时间 |
| 真题修订 | `cm_learning_session.collection_revision_id` | 读取历史真题名称，不使用当前修订 |
| 会话题序和题目版本 | `cm_session_question.question_id/question_revision_id/question_order` | 按当时题序回放 |
| 冻结题面 | `cm_session_question.presentation_snapshot` | 完整题干、选项、图片、题型 |
| 冻结答案和解析 | `cm_session_question.grading_snapshot` | 正确答案、题库解析、单题满分 |
| 冻结知识点 | `cm_session_question.knowledge_snapshot` | 会话知识点摘要，不回查当前知识树覆盖历史 |
| 当时作答 | `cm_attempt_answer.answer_data` | 选择题选项数组、主观题文本 |
| 评分事实 | `cm_attempt_answer.score/max_score/score_rate/grading_status/graded_time` | 对错、分数、评分状态 |
| AI 评分来源和修订 | `cm_attempt_answer.grading_source/grading_revision_no` | 正式考试主观题评分来源 |
| AI 评分结果 | `cm_attempt_answer.grading_result` | `feedback`、`itemResults[].code/scoreRate` 或失败码 |
| 冻结 AI 量规 | `cm_session_question.ai_rubric_snapshot` | `items[].code/description/weight` |

知识点练习结束时会依次把会话推进到 `submitted`、`settling`、`completed` 并写入 `submitted_time`、`settled_time`。未提交题不会补建 `cm_question_attempt` 或 `cm_attempt_answer`，因此历史详情必须允许“会话已完成但某题未作答”。

历年真题练习同样使用 `past_paper_practice` 会话、冻结会话题和逐题答案。现行契约明确只支持 `CHOICE`；含 `CASE` 或 `ESSAY` 的真题卷不提供练习入口。

正式考试通过 `FormalExamEngine` 支持 `CHOICE/CASE/ESSAY`。主观题答案使用 `subjective_answer/1.0` 的 `answer_data.value` 保存；AI 成功后保存分数、`grading_source='AI'`、`grading_revision_no` 和 `grading_result`，同时保留 `ai_rubric_snapshot`。现有 `FormalExamResultVo` 已经证明这些事实可以被安全投影为用户可读结果，但当前学习记录考试详情没有复用这些字段。

### 2.3 不需要新增业务事实表

完成本次历史查询不需要复制答案、解析或 AI 评分，也不需要新增学习记录事实表。读模型必须直接从上述会话、冻结快照和作答评分事实查询。

建议只新增一个查询性能索引；不新增答案列或冗余结果列：

```sql
CREATE INDEX IF NOT EXISTS idx_cm_learning_session_completed_practice_history
    ON cm_learning_session(user_id, goal_id, settled_time DESC, id DESC)
    WHERE session_type IN ('self_practice', 'past_paper_practice')
      AND status = 'completed'
      AND settled_time IS NOT NULL;
```

索引必须放入新的有序 PostgreSQL 迁移文件，不能修改已部署迁移。

## 3. 目标页面结构

页签改为：

1. 每日任务；
2. 练习历史；
3. 考试历史。

练习历史列表每行展示：

- 类型：知识点练习或历年真题练习；
- 标题：知识点练习固定显示“知识点练习”，真题练习取会话关联的 `cm_collection_revision.collection_name`；
- 科目和冻结知识点摘要；
- 题目总数、已答、答对、答错、未作答；
- 完成日期，仅显示 `YYYY-MM-DD`；
- “查看详情”。

知识点练习开始时没有把用户点击的上层知识点单独存入会话字段，所以历史列表不得伪造“当时选择的知识点名称”。本版只展示会话各题 `knowledge_snapshot.items[]` 去重后的冻结知识点摘要。若以后产品必须精确显示开始练习时点击的节点，需要另立迁移在创建会话时冻结练习上下文，不能回查当前知识树猜测。

练习详情使用逐题卡片或折叠面板，不再使用只能容纳摘要的横向表格。每道选择题展示：

- 完整冻结题干和图片；
- 全部冻结选项；
- 用户当时选择；
- 冻结正确答案；
- 正确、错误或未作答状态；
- 得分和题库解析。

未作答题显示“本次未作答”。会话已经完成后允许展示冻结正确答案和解析，但不得为未作答题伪造 attempt、分数或作答时间。

考试历史详情沿用现有考试列表，只增强每道题的回放：选择题按上述方式展示；`CASE/ESSAY` 展示用户当时的文字答案、参考答案、题库解析、AI 得分、AI 总评和逐评分项结果。

## 4. 新练习历史接口契约

以下两个路由是本次拟新增的学习记录只读接口，不是现有接口。它们归属 `LearningHistoryController`，继续使用 `certmuse:student` 与 `certmuse:learning:history:query` 的 AND 权限。

### 4.1 练习会话列表

```http
GET /api/learning/history/practices
```

查询参数：

| 参数 | 类型 | 必填 | 规则 |
| --- | --- | ---: | --- |
| `goalId` | string | 否 | 沿用现有学习记录目标解析和所有权规则 |
| `practiceType` | enum | 否 | `KNOWLEDGE_PRACTICE`、`PAST_PAPER_PRACTICE` |
| `completedFrom` / `completedTo` | date | 否 | `YYYY-MM-DD`，按 `Asia/Shanghai` 过滤 |
| `pageNum` / `pageSize` | integer | 否 | 沿用现有学习记录分页边界 |

固定按 `settled_time DESC, session_id DESC` 排序。示例中的字段均为新读模型字段，但每一项都有现有数据库来源：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "rows": [{
      "sessionId": "900000000000000801",
      "practiceType": "KNOWLEDGE_PRACTICE",
      "title": "知识点练习",
      "subject": {"id": "101", "name": "综合知识"},
      "knowledgePoints": [{"id": "201", "name": "软件架构风格"}],
      "questionCount": 10,
      "answeredCount": 7,
      "correctCount": 5,
      "incorrectCount": 2,
      "unansweredCount": 3,
      "completedAt": "2026-08-20T15:42:10+08:00"
    }],
    "total": 1
  }
}
```

统计口径：

- `questionCount`：会话的 `cm_session_question` 数量；
- `answeredCount`：存在有效已提交 attempt 和非 `invalid` answer 的题数；
- `correctCount`：有效答案 `grading_status='graded' AND score_rate=1`；
- `incorrectCount`：有效答案 `grading_status='graded' AND score_rate<1`；
- `unansweredCount = questionCount - answeredCount`；
- 当前两类练习都只有同步判分选择题，完成会话若出现 `pending/failed` 评分属于数据一致性错误，返回 `HISTORY_READ_FAILED`，不得归入错误或未作答。

### 4.2 单次练习详情

```http
GET /api/learning/history/practices/{sessionId}?goalId=...
```

只允许读取当前用户、选定目标、类型为 `self_practice/past_paper_practice`、状态为 `completed` 且 `settled_time` 非空的会话。不存在、越权、跨目标、未完成或类型不符统一返回 404 `HISTORY_PRACTICE_NOT_FOUND`。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "sessionId": "900000000000000801",
    "practiceType": "PAST_PAPER_PRACTICE",
    "title": "2025年系统架构设计师综合知识真题",
    "subject": {"id": "101", "name": "综合知识"},
    "startedAt": "2026-08-20T15:10:00+08:00",
    "completedAt": "2026-08-20T15:42:10+08:00",
    "summary": {
      "questionCount": 2,
      "answeredCount": 1,
      "correctCount": 0,
      "incorrectCount": 1,
      "unansweredCount": 1
    },
    "questions": [{
      "questionId": "301",
      "questionOrder": 1,
      "questionType": "CHOICE",
      "difficulty": "MEDIUM",
      "stem": "完整冻结题干",
      "selectionMode": "single",
      "options": [
        {"label": "A", "content": "选项A"},
        {"label": "B", "content": "选项B"}
      ],
      "images": [],
      "knowledgePoints": [{"id": "201", "name": "软件架构风格"}],
      "submission": {
        "submitted": true,
        "selectedOptionLabels": ["A"],
        "submittedAt": "2026-08-20T15:15:00+08:00"
      },
      "result": {
        "attemptResult": "INCORRECT",
        "score": "0",
        "maxScore": "1",
        "scoreRate": 0,
        "correctOptionLabels": ["B"],
        "analysis": "冻结题库解析"
      }
    }]
  }
}
```

字段映射必须固定：

- `stem/options/images/questionType` 来自 `presentation_snapshot`；
- `selectionMode` 优先读取冻结快照中的规则。旧 `past_paper_practice` 快照若没有该字段，只能按现行服务端“一题恰好一个选项”的持久化规则兼容为 `single`，不能根据前端选中数量猜测；
- `selectedOptionLabels` 来自 `answer_data.value`，始终返回数组；
- `correctOptionLabels` 来自 `grading_snapshot.answer.value`；
- `analysis` 来自 `grading_snapshot.analysis`；
- `score/maxScore/scoreRate/gradingStatus` 来自 `cm_attempt_answer`；
- 图片继续通过 `QuestionImageUrlService` 生成受控 URL，不返回 `storagePath`；
- 所有内容使用该 `cm_session_question` 的冻结快照，不查询当前 `cm_question_revision`、当前选项或当前知识点覆盖历史。

未提交题返回 `submission=null`；`result.attemptResult/score/maxScore/scoreRate` 均为 `null`，但完成会话仍可从冻结 `grading_snapshot` 返回 `correctOptionLabels` 和 `analysis`。不得把“没有 attempt”转换成 `SKIPPED` 或 `INCORRECT`。

## 5. 考试历史详情增强

保留现有：

```http
GET /api/learning/history/exams/{sessionId}?goalId=...
```

扩展 `questions[]`，字段语义与已经实现的 `FormalExamResultVo.ItemResultVo` 对齐，不直接返回 JSONB：

```json
{
  "questionId": "401",
  "questionOrder": 2,
  "questionType": "CASE",
  "difficulty": "HARD",
  "stem": "完整冻结题干",
  "options": [],
  "images": [],
  "submission": {
    "selectedOptionLabels": [],
    "textAnswer": "用户当时提交的案例题答案",
    "unanswered": false
  },
  "result": {
    "correct": null,
    "score": "6",
    "maxScore": "10",
    "scoreRate": 0.6,
    "correctOptionLabels": [],
    "referenceAnswer": "冻结参考答案",
    "analysis": "冻结题库解析",
    "gradingStatus": "graded",
    "gradingSource": "AI",
    "gradingRevisionNo": 1,
    "aiFeedback": "AI 对本次答案的中文总评",
    "gradingItems": [{
      "code": "KEY_POINT_1",
      "description": "评分项说明",
      "weight": 0.5,
      "scoreRate": 0.8
    }]
  }
}
```

主观题映射规则：

- `submission.textAnswer`：`answer_data.value`；
- `referenceAnswer`：`grading_snapshot.answer.value`；
- `analysis`：`grading_snapshot.analysis`，与 AI 总评分开；
- `aiFeedback`：`grading_result.feedback`；
- `gradingItems[].code/scoreRate`：`grading_result.itemResults[]`；
- `gradingItems[].description/weight`：按 `code` 与 `ai_rubric_snapshot.items[]` 匹配；
- `score/maxScore/scoreRate/gradingStatus/gradingSource/gradingRevisionNo`：`cm_attempt_answer` 对应列；
- `grading_status='failed'` 时保留用户答案和参考答案，分数与 AI 反馈按现有正式考试安全规则处理，并显示“AI 评分失败”；不得把失败伪装成 0 分已评分；
- `grading_status='pending'` 时显示“AI 评分中”，不返回不存在的 AI 总评或逐项结果；
- 不返回 `cm_ai_grading_task.payload/result` 原文、供应商请求、内部异常或未经过结构校验的内容。

选择题考试详情使用同一个外层结构，但 `submission.textAnswer=null`，使用 `selectedOptionLabels`；`referenceAnswer=null`，使用 `correctOptionLabels`；AI 字段为空。

### 6.3 数据库迁移和部署前核验

新增索引迁移，不改旧迁移。部署前先以只读 SQL 核验目标库实际结构：

```sql
SELECT table_name, column_name
FROM information_schema.columns
WHERE table_schema='public'
  AND table_name IN ('cm_learning_session','cm_session_question','cm_question_attempt','cm_attempt_answer')
  AND column_name IN (
    'session_type','status','settled_time','collection_revision_id',
    'presentation_snapshot','grading_snapshot','knowledge_snapshot','ai_rubric_snapshot',
    'answer_data','score','max_score','score_rate','grading_status',
    'grading_result','grading_source','grading_revision_no'
  )
ORDER BY table_name, column_name;
```

只核验数量和状态，不输出答案正文：

```sql
SELECT session_type, status, count(*)
FROM cm_learning_session
WHERE session_type IN ('self_practice','past_paper_practice','past_paper_exam','simulation')
GROUP BY session_type, status
ORDER BY session_type, status;
```

若目标库缺少 `grading_result/ai_rubric_snapshot/grading_source/grading_revision_no`，必须先补齐现有主观题和正式考试迁移，不能在历史查询里用同名临时字段兜底。

## 8. 错误、安全和数据一致性

- 新增 `HISTORY_PRACTICE_NOT_FOUND`，用于不存在、越权、跨目标、未完成和类型不符；不泄露资源是否存在。
- 列表和详情继续复用 `HISTORY_REQUEST_INVALID`、`HISTORY_GOAL_NOT_FOUND`、`HISTORY_GOAL_REQUIRED`、`HISTORY_READ_FAILED`。
- 雪花 ID 对外一律使用字符串；分数使用十进制字符串，`scoreRate` 使用 0 至 1 的 JSON number。
- 不在日志记录题干全文、选项、用户答案、正确答案、解析、AI 反馈、量规或完整响应。
- 不把当前题库内容回填历史；当前题目修改、下架、选项调整或知识树改名均不能改变旧会话详情。
- 不向前端返回原始 JSONB，服务端只投影契约字段并做结构校验。
- `questionCount = answeredCount + unansweredCount`，当前练习还必须满足 `answeredCount = correctCount + incorrectCount`；不守恒返回 500。
- 主观题 `gradingItems` 必须按 `code` 与冻结量规一一匹配；重复、缺失或未知 code 属于历史评分事实损坏。

## 9. 验收用例

1. 同一道题在三次知识点练习中作答，练习历史显示三条会话，不再合并成一条题目历史。
2. 知识点练习只提交 7/10 题后结束，列表显示 7 已答、3 未答；详情保留 10 道冻结题，但未答题没有伪造 attempt 和分数。
3. 真题练习完成后，标题来自该会话关联的题集修订；真题发布新修订后旧记录名称、题序、题干和选项不变化。
4. 选择题详情显示全部选项、当时选择、正确答案和题库解析；多选答案保持数组并按冻结选项顺序展示。
5. 完成日期列表只显示 `2026-08-20`，不显示后续时间；详情仍可显示完整完成时间。
6. `past_paper_exam`、`simulation`、每日任务、订正和首次诊断不会混入练习历史。
7. 正式考试 CASE 题显示用户原文、参考答案、题库解析、AI 总评和每个量规项的说明、权重及得分率。
8. 主观题 AI 评分中时保留用户答案并显示处理中；评分失败时显示失败，不伪装为正常 0 分；成功时总分与逐项评分事实一致。
9. 当前题库修订或知识点改名后，历史详情仍使用会话冻结快照。
10. 他人、跨目标、未完成或不支持类型的 `sessionId` 返回统一 404，不泄露题目、标题、答案或分数。
