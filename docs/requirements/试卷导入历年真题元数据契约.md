# 试卷导入历年真题元数据契约

## 目标

管理端通过 `POST /api/admin/paper-imports` 导入历年真题时，预检通过并确认导入后，必须创建带有完整历年真题元数据的题集草稿。新建题集和导入试卷均不再提供“专项题集”作为新建选项；既有该类型的题集不受影响。

## 请求

接口仍使用 `multipart/form-data`，保留既有的 `file`、`collectionName`、`collectionType`、`durationMinutes` 与 `certificationId` 字段。

当 `collectionType=PAST_PAPER` 时，以下字段必填：

| 字段 | 约束 |
| --- | --- |
| `examYear` | 1990–2100 的整数 |
| `examMonth` | `5` 或 `11` |
| `paperTypeCode` | 去除首尾空白后 1–50 个字符 |
| `paperTypeName` | 去除首尾空白后 1–100 个字符 |

非历年真题不提交这些字段，服务端保持既有创建与预检行为。

## 成功与失败

- 成功创建批次仍返回既有 `R<ImportBatchVo>`，并在预检、确认之间保存上述元数据。
- 确认成功后，创建的 `cm_collection` 草稿保留相同的年份、批次、卷型编码和卷型名称。
- 无效元数据返回 HTTP 400，`data.errorCode=IMPORT_CONTEXT_INVALID`，`fieldErrors` 指向对应字段；不会创建导入批次或题集草稿。

## 验收

1. 导入试卷的类型下拉包含“历年真题”，不包含“专项题集”。
2. 选择历年真题时，未完整填写四项元数据不能开始预检。
3. 通过预检并确认后，生成的历年真题草稿通过 `cm_collection` 的历年真题元数据约束。
4. 新建题集入口同样不显示“专项题集”。
