# 题目 ZIP 人工评分点兼容契约 V1

> 状态：`deprecated`
> 生效日期：2026-08-18
> 替代规则：题库不再保存、展示或校验人工评分点。

## 请求规则

题目 ZIP 仍使用 `question-zip/1.0` 及既有创建、预检、确认和问题查询接口。CASE/ESSAY 的正式记录只包含题目内容、参考答案、解析、图片和题目级知识点，不包含 `scoring_points`。

为兼容升级期间已经生成的旧文件：

- 省略 `scoring_points`：正常预检和导入。
- 传入 `scoring_points: []`：正常预检和导入，规范化结果不保留该字段。
- 传入非空数组、对象、`null` 或其他值：产生 `QUESTION_SCORING_POINTS_UNSUPPORTED`，`fieldPath=scoring_points`，`severity=error`，阻断确认。

选择题和主观题执行相同的兼容规则。服务端不得静默丢弃非空人工评分点。

## 成功与失败响应

接口继续返回既有 `R<T>` 和异步批次状态。兼容空数组不会增加响应字段；不支持错误通过 `GET /api/admin/imports/{id}/issues` 返回，并计入批次失败数量。

## 持久化与内容身份

- 规范化结果和内容哈希不包含评分点。
- 确认导入不写入评分点或评分点知识点关系。
- 主观题参考答案仍必填；缺失时沿用题目答案错误码。
- 题目级知识点继续用于检索、审核和未来能力归因设计。
- 试卷题分由 `cm_collection_item.report_score` 保存，不从题库评分点计算。

## 验收用例

1. CASE/ESSAY 省略评分点，预检及确认成功。
2. 任意题型传空数组，预检及确认成功，规范化记录无评分点字段。
3. 任意题型传非空评分点，产生稳定的不支持错误并阻断确认。
4. 仅改变旧文件中的空数组与省略形式，不改变内容哈希。
5. 导入完成后数据库不存在人工评分点写入。
