# 学习画像页面后端接口契约 V1

```yaml
contract_id: learner-current-profile-v1
contract_version: 1.0
module: learning-profile
route: /api/learning/profile/current
scope: learner-current-profile-read-model
status: superseded_draft
updated_at: 2026-08-17
```

> 本草案已由《学习画像总分后端接口契约V1》替代，不得据此实现接口。学生端当前仅需要资格总分接口；知识点重要度和掌握状态继续复用 U08 知识点练习设置接口。

## 1. 目标与边界

本契约为学生端“学习画像”页提供当前学习目标下的一致只读快照。一次响应同时提供目标范围、状态总览、分科摘要、重点关注项和全量知识点树，树视图与列表视图不得分别读取不同时间的画像数据。

页面只向学员表达“未评估、暂定、紧急、薄弱、学习中、熟练、待验证、待复核、已失效”等业务状态；不返回或展示能力分、通过概率、准备度结论、计算公式、原始证据、规则参数和内部审计字段。

本接口不创建或修改目标、作答、画像、任务、错题或报告；不替代知识点练习、首次诊断和历史报告接口。无有效证据是正常空画像，不是错误。

## 2. 接口定义

```http
GET /api/learning/profile/current
```

- 无请求体和查询参数；不要求 `X-Request-Id`，客户端携带该请求头时不得据此拒绝请求或产生写入。
- 仅允许已登录学员；用户和目标范围均从服务端会话取得，禁止传递 `userId`、`goalId`、资格、考纲或科目参数。
- 权限为 `certmuse:student` 与新增的 `certmuse:learning:profile:query`，两项均为必需。
- 当前可查看目标为 `active` 或 `paused`。暂停目标只读返回；没有可查看目标时返回 409。

## 3. 成功响应

真实 HTTP Status 必须为 200，且等于 `R.code`。所有 ID 以字符串返回；时间为 ISO-8601 带时区时间。

```ts
type ProfileState = 'EMPTY' | 'AVAILABLE';
type ProfileStatus =
  | 'unassessed' | 'provisional' | 'urgent' | 'weak' | 'learning'
  | 'proficient' | 'mastery_candidate' | 'mastered' | 'needs_retest'
  | 'pending_verification' | 'needs_review' | 'expired';

interface CurrentProfileVo {
  goal: {
    id: string;
    certificationName: string;
    syllabusVersionName: string;
    status: 'ACTIVE' | 'PAUSED';
  };
  profileState: ProfileState;
  snapshotTime: string;
  overview: {
    unassessedCount: number;
    provisionalCount: number;
    needStrengthenCount: number;
    learningCount: number;
    stableCount: number;
    specialAttentionCount: number;
  };
  subjects: Array<{
    id: string;
    name: string;
    summary: CurrentProfileVo['overview'];
    nodes: ProfileKnowledgeNodeVo[];
  }>;
  focusItems: Array<{
    knowledgePointId: string;
    syllabusNumber: string;
    syllabusTitle: string;
    examSubjectId: string;
    examSubjectName: string;
    importance: 1 | 2 | 3;
    profileStatus: ProfileStatus;
    reasonCode: 'CORE_WEAKNESS' | 'PENDING_VERIFICATION' | 'EVIDENCE_CONFLICT' | 'VERIFICATION_FAILED' | 'EVIDENCE_EXPIRED';
    reasonText: string;
    action: 'PRACTICE';
    practiceAvailable: boolean;
  }>;
}

interface ProfileKnowledgeNodeVo {
  id: string;
  syllabusNumber: string;
  syllabusTitle: string;
  treeDepth: number;
  sortOrder: number;
  importance: 1 | 2 | 3;
  profileStatus: ProfileStatus;
  practiceAvailable: boolean;
  children: ProfileKnowledgeNodeVo[];
}
```

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "goal": { "id": "9001", "certificationName": "系统架构设计师", "syllabusVersionName": "第二版", "status": "ACTIVE" },
    "profileState": "AVAILABLE",
    "snapshotTime": "2026-08-17T10:20:00+08:00",
    "overview": { "unassessedCount": 18, "provisionalCount": 5, "needStrengthenCount": 4, "learningCount": 8, "stableCount": 3, "specialAttentionCount": 2 },
    "subjects": [],
    "focusItems": []
  }
}
```

### 3.1 返回规则

- **统计范围**固定为当前目标考纲中启用且未删除的叶子知识点。父节点只用于完整树展示，绝不进入 `overview` 或 `subjects[].summary`，避免父子重复计数。
- `EMPTY` 表示统计范围内所有叶子均为 `unassessed`。完整树仍返回且所有节点状态为 `unassessed`；`unassessedCount` 等于统计叶子数，其余五项均为 0，`focusItems` 为空。
- `AVAILABLE` 表示至少一个统计叶子不是 `unassessed`。`expired` 也是 `AVAILABLE` 的状态：它保留历史画像展示、进入重点关注，但不表示当前有效掌握。总览和科目摘要均由同一快照中的统计叶子汇总，不以任何单场报告、正确率或能力分替代。
- `overview` 必须等于所有科目 `summary` 各字段之和。`needStrengthenCount` 只统计 `urgent`、`weak`；`learningCount` 只统计 `learning`；`stableCount` 统计 `proficient`、`mastery_candidate`、`mastered`；`specialAttentionCount` 统计 `needs_retest`、`pending_verification`、`needs_review`、`expired`。状态互斥，未列入上述分组的状态只由其专属计数或节点展示表达。
- `focusItems` 最多返回 10 项，只能来自以下映射：`expired → EVIDENCE_EXPIRED`、`needs_review → VERIFICATION_FAILED`、`needs_retest → EVIDENCE_CONFLICT`、`pending_verification → PENDING_VERIFICATION`、重要度为 3 的 `urgent/weak → CORE_WEAKNESS`；`action` 固定为 `PRACTICE`。前端不得自行重算原因、动作或排序。
- `focusItems` 固定按 `expired`、`needs_review`、`needs_retest`、`pending_verification`、核心 `urgent`、核心 `weak` 的顺序排序；同一分组按 `importance` 降序、`sortOrder` 升序、`knowledgePointId` 升序。`practiceAvailable=false` 时仍返回重点项，但前端不展示“去练习”。
- 节点树包含当前目标考纲的所有启用未删除节点；当前资格的启用科目即使无节点也返回空 `nodes`。科目按平台既有业务顺序，兄弟节点按 `sortOrder`、ID 升序。孤儿节点、跨科父子关系、循环引用或无法组成完整树时，整次请求返回安全 500，不返回残缺树。
- `practiceAvailable=true` 当且仅当该 ID 在同一 `REPEATABLE_READ` 只读快照中符合 U08 知识点练习的合法启动节点规则；它不表示题目数量、能力结论或学习任务。`learning` 读模型必须通过 `assessment` 的显式 Service 取得此事实，不得复制练习 SQL 或跨域访问 Mapper。
- 服务端必须在一致性读取中生成整个响应；`snapshotTime` 是本次投影读取时间，不是假装的证据更新时间。V1 不启用缓存。

## 4. 失败响应

业务失败使用稳定的 `data.errorCode`；前端只根据该字段分支，`msg` 仅作脱敏兜底。401/403 沿用既有认证格式，`data` 不作承诺。

```json
{
  "code": 409,
  "msg": "当前没有可查看的学习目标",
  "data": {
    "errorCode": "LEARNING_GOAL_NOT_ACTIVE",
    "retryable": false,
    "traceId": null,
    "fieldErrors": [],
    "details": null
  }
}
```

| HTTP / `R.code` | `errorCode` | 条件 | `retryable` | 前端行为 |
| --- | --- | --- | ---: | --- |
| 401 / 403 | 不承诺 | 未登录、非学员或无任一必需权限。 | 不承诺 | 交由全局登录或无权限处理。 |
| 409 | `LEARNING_GOAL_NOT_ACTIVE` | 没有 `active` 或 `paused` 目标。 | false | 展示无目标状态，进入目标设置。 |
| 500 | `CURRENT_PROFILE_SYSTEM_FAILURE` | 未预期的读取、聚合或序列化失败。 | true | 保留页面骨架，提供重新加载，并展示 `traceId`。 |

## 5. 行为、安全与可观测性

- 接口只读取调用者的当前目标；不得通过路径、参数或缓存键查询其他用户、历史目标、其他资格或其他考纲。
- 不返回 `current_direct_ability`、`baseline_direct_ability`、`freshness`、可信度、证据数量、证据时间、规则版本、数据库状态、答案、题目、错题或报告内容。
- 访问日志仅记录用户、目标、`profileState`、节点数量、重点项数量、耗时、结果码与 `traceId`；不得记录原始证据、答案或完整响应。
- 本接口不产生学习事件、画像变化、缓存写入或异步任务。V1 不启用缓存。

## 6. 验收用例

1. 有进行中目标且存在多个知识点画像：200，所有区域共享同一 `snapshotTime`，不返回能力数值。
2. 有暂停目标：200，只读返回该目标画像；不会创建任务或改变状态。
3. 有目标但没有任何有效证据：200，`profileState='EMPTY'`，树可用、无重点项、无默认薄弱项；未评估叶子数在总览与科目摘要中准确相加。
4. 仅部分科目被评估：200，未评估科目完整返回并保持 `unassessed`，不得补分。
5. 存在核心紧急项、待验证项、待复核项或过期项：重点项返回冻结的原因码、`PRACTICE` 动作和正确排序；不可练项不隐藏、不提供练习按钮。
6. 树节点同时用于树视图与列表视图：每个节点只出现一次，编号、名称、状态、重要度和排序字段一致；父节点不进入统计。
7. 没有可查看目标：409 `LEARNING_GOAL_NOT_ACTIVE`，不泄露历史目标或其他资格数据。
8. 未登录、非学员或权限不足：沿用 401/403 兼容响应，不返回画像数据。
9. 全部画像已过期：200，`profileState='AVAILABLE'`，过期叶子计入特别关注项并进入重点项排序。
10. 聚合读取或目录建树失败：500 `CURRENT_PROFILE_SYSTEM_FAILURE`，带非空 `traceId`，不返回内部错误、SQL、证据或残缺树。

## 7. 实施入口

- 后端：`backend/ruoyi-modules/ruoyi-certmuse` 的 `learning` 读模型协调 `profile`、`catalog` 与 `assessment` Service；禁止跨域直接访问 Mapper。读取使用 `REPEATABLE_READ`；画像领域异常或专用 Advice 必须将未预期失败转换为 `CURRENT_PROFILE_SYSTEM_FAILURE`，不能落入通用 `INTERNAL_SERVER_ERROR`。
- 前端：`web/student/src/api/certmuse/learning/profiles.ts` 与 `/learning/progress` 页面。
- 数据：画像数据结构只读、无回填、无写入；但新增 `certmuse:learning:profile:query` 必须通过独立有序权限种子迁移创建权限/菜单并授权学员角色。该迁移是实现前置条件，不在本契约轮次执行。
